Automatización de Auditorías de Seguridad con Bash

Objetivo del Proyecto

Desarrollar un script que pudiera realizar las siguientes tareas de forma automática:

1.Verificar si el sistema tiene parches de seguridad pendientes.

2.Comprobar la configuración del firewall (UFW).

3.Identificar cuentas inactivas o con privilegios de root que podrían representar un riesgo.

4.Generar un reporte consolidado con la información recolectada.

Creación del Script

Paso 1: Configuración del Entorno

Primero, abre la terminal y actualiza el sistema:

sudo apt update && sudo apt upgrade -y

Luego crea un nuevo archivo en tu directorio de trabajo para escribir el script:

nano auditoria.sh

Paso 2: Escribe el Código

Añade las siguientes líneas al archivo para que el script cubriera cada objetivo definido:

Script de Auditoría de Seguridad Revisado

auditoria.sh.

#!/bin/bash

# --- Configuración y Variables ---

DATE=$(date +%Y-%m-%d_%H%M%S)

REPORT_FILE="reporte_auditoria_${DATE}.txt"

# Usamos 'tee -a' en lugar de redireccionar varias veces para simplificar

# y asegurar que el contenido se muestra en pantalla y se guarda en el archivo.

# Inicialmente limpiamos el archivo de reporte, luego siempre usamos -a (append)

# --- Encabezado del Reporte ---

echo "==================================================" | tee "$REPORT_FILE"

echo " REPORTE DE AUDITORÍA DE SEGURIDAD " | tee -a "$REPORT_FILE"

echo "Fecha: $(date)" | tee -a "$REPORT_FILE"

echo "==================================================" | tee -a "$REPORT_FILE"

echo "" | tee -a "$REPORT_FILE"

# --------------------------------------------------

# #1. Verificar Actualizaciones y Parches de Seguridad

# --------------------------------------------------

echo "### [1] Verificando Actualizaciones y Parches de Seguridad..." | tee -a "$REPORT_FILE"

sudo apt update > /dev/null

echo "Actualizaciones pendientes:" | tee -a "$REPORT_FILE"

# Se usa 'apt list --upgradable' que es más estándar que 'apt-get -s upgrade | grep Inst'

apt list --upgradable 2>/dev/null | grep -v 'Listing...' | tee -a "$REPORT_FILE"

echo "Actualizaciones pendientes listadas." | tee -a "$REPORT_FILE"

echo "" | tee -a "$REPORT_FILE"

# --------------------------------------------------

# #2. Comprobar configuración de Firewall (UFW)

# --------------------------------------------------

echo "### [2] Verificando configuración de Firewall (UFW)..." | tee -a "$REPORT_FILE"

if sudo ufw status | grep -q "active"; then

echo "Firewall está habilitado (activo)." | tee -a "$REPORT_FILE"

# Muestra las reglas detalladas

sudo ufw status verbose | tee -a "$REPORT_FILE"

else

echo "⚠️ ¡Firewall NO está habilitado (inactivo)!" | tee -a "$REPORT_FILE"

fi

echo "" | tee -a "$REPORT_FILE"

# --------------------------------------------------

# #3. Detectar cuentas de usuario con acceso root

# --------------------------------------------------

echo "### [3] Revisando cuentas con privilegios de root..." | tee -a "$REPORT_FILE"

echo "Cuentas con UID=0 (Root):" | tee -a "$REPORT_FILE"

# El campo ':$3' debe ser ':$3=='0'' para buscar el UID 0.

# Además, se puede incluir el nombre del usuario ($1) y la shell ($7)

awk -F: '($3 == "0") {print "Usuario: "$1", UID: "$3", Shell: "$7}' /etc/passwd | tee -a "$REPORT_FILE"

echo "Cuentas con UID=0 listadas." | tee -a "$REPORT_FILE"

echo "" | tee -a "$REPORT_FILE"

# --------------------------------------------------

# #4. Detectar usuarios inactivos

# --------------------------------------------------

echo "### [4] Buscando inicios de sesión recientes y fallidos..." | tee -a "$REPORT_FILE"

# El grep original ('grep "Never logged in"') solo funciona en algunas distribuciones.

# Usamos 'lastlog' y filtramos usuarios con 'Never logged in' o una fecha muy antigua.

echo "Usuarios que nunca han iniciado sesión o con inicio de sesión muy antiguo (requiere revisión manual):" | tee -a "$REPORT_FILE"

sudo lastlog | grep -E 'Never|**' | tee -a "$REPORT_FILE"

echo "Inicios de sesión inactivos/antiguos listados." | tee -a "$REPORT_FILE"

echo "" | tee -a "$REPORT_FILE"

# --------------------------------------------------

# #5. Escaneo básico de puertos abiertos

# --------------------------------------------------

echo "### [5] Escaneo básico de puertos abiertos..." | tee -a "$REPORT_FILE"

# Se usa 'ss -tuln' que es el reemplazo moderno y más rápido de 'netstat -tuln'

echo "Puertos abiertos (LISTEN) en TCP y UDP (IPv4 e IPv6):" | tee -a "$REPORT_FILE"

sudo ss -tuln | tee -a "$REPORT_FILE"

echo "Puertos abiertos listados." | tee -a "$REPORT_FILE"

echo "" | tee -a "$REPORT_FILE"

# --------------------------------------------------

# Conclusión

# --------------------------------------------------

echo "==================================================" | tee -a "$REPORT_FILE"

echo "Auditoría finalizada. Revisa el archivo de reporte: $REPORT_FILE" | tee -a "$REPORT_FILE"

echo "==================================================" | tee -a "$REPORT_FILE"

1. Variables y Salida

  • Se definió $REPORT_FILE y se utiliza | tee -a "$REPORT_FILE" para que la salida se muestre en la terminal (por donde lo estás ejecutando) y, a la vez, se guarde en el archivo de reporte (-a para añadir contenido).

2. Actualizaciones

  • apt list --upgradable, que es el método moderno y más claro en Ubuntu/Debian para listar paquetes que pueden actualizarse.

3. Firewall

  • Usa ufw status. El módulo ufw está instalado por defecto en Ubuntu 24.04, por lo que este chequeo es muy pertinente.

4. Cuentas Root

  • awk -F: '($3 == "0") {print "Usuario: "$1",..."}'. Esto filtra exactamente las cuentas con UID 0 (root), que son las que tienen privilegios máximos, y te da más información de contexto.

5. Usuarios Inactivos

  • uso de lastlog, pero se mejoró el filtro para buscar patrones que indiquen un inicio de sesión nunca realizado (Never) o uno con una fecha no registrada (**).

6. Escaneo de Puertos (Actualizado)

  • ss -tuln. El comando ss (Socket Statistics) es el reemplazo moderno de netstat y es mucho más rápido y preferido en sistemas Linux recientes como Ubuntu 24.04.

Pasos para la Implementación

  1. Guarda el script: Copia el código revisado y guárdalo en un archivo llamado auditoria.sh.

  2. Da permisos de ejecución:

chmod +x auditoria.sh

  1. Ejecútalo:

sudo ./auditoria.sh

(Se requiere sudo para ejecutar apt update, ufw status, ss, y lastlog).

Al finalizar, verás la salida en la terminal y se generará un archivo llamado reporte_auditoria_YYYY-MM-DD_HHMMSS.txt en el mismo directorio con todos los hallazgos.

Al abrirlo con cat o nano, pude ver un resumen detallado:

1.Actualizaciones pendientes: Una lista de paquetes que necesitan ser actualizados, identificando posibles parches críticos.

2.Firewall: Confirmó si el firewall estaba habilitado y mostró detalles sobre las reglas configuradas.

3.Cuentas con UID 0: Identificó si había usuarios con privilegios de root, lo cual es crucial para la seguridad.

4.Usuarios inactivos: Listó cuentas que nunca habían iniciado sesión.

5.Puertos abiertos: Un mapeo de los servicios escuchando en la máquina.
