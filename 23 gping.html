Instalación de gping

Ping, pero con un gráfico.

  • Grafica el tiempo de ping para varios hosts

  • Grafica el tiempo de ejecución de los comandos a través del --cmdBandera

  • Colores personalizados

  • Soporte de Windows, Mac y Linux

La herramienta está escrita en Rust y se puede instalar de diversas maneras dependiendo de su sistema operativo:

Sistemas Operativos Populares

Sistema Método de Instalación Comando
macOS Homebrew brew install gping
macOS MacPorts sudo port install gping
Windows Scoop scoop install gping
Windows Chocolatey choco install gping
Arch Linux Pacman sudo pacman -S gping
Alpine Linux APK apk add gping
Ubuntu/Debian APT (para versiones >23.10/>13) sudo apt install gping

Instalación Universal (Requiere Rust)

Si tienes Rust instalado (versión 1.67.0 o superior), puedes instalar gping usando Cargo:

cargo install gping

Docker

También puedes ejecutar gping dentro de un contenedor Docker (asegúrate de usar la opción --network host):

docker run --rm -ti --network host ghcr.io/orf/gping:gping-v1.15.1 google.com

Ejemplos de Uso de gping

El comando principal es simple: gping [host]. También permite opciones avanzadas como graficar la ejecución de comandos.

1. Ping Básico

Simplemente ejecute gping seguido del host o la dirección IP.

gping google.com

2. Ping a Múltiples Hosts

Puede monitorear el tiempo de respuesta de varios destinos simultáneamente. Cada uno aparecerá como una línea separada en el gráfico.

gping google.com cloudflare.com 8.8.8.8

3. Graficar la Ejecución de Comandos (--cmd)

Utilice la opción --cmd para graficar el tiempo que tarda en ejecutarse un comando de shell en lugar de un ping. Esto es útil para monitorear el rendimiento de tareas recurrentes.

gping --cmd "curl -sI http://example.com"

4. Opciones Comunes

Opción Descripción Ejemplo
-n o --watch-interval Define el intervalo entre monitoreos en segundos (admite decimales). gping -n 0.5 google.com
-b o --buffer Determina cuántos segundos de datos se mostrarán en el gráfico (por defecto 30s). gping -b 60 google.com
-4 / -6 Fuerza la resolución del host a IPv4 o IPv6. gping -4 google.com
-c o --color Asigna un color específico a una entrada del gráfico. gping -c red google.com
--clear Limpia el gráfico de la terminal al cerrar el programa. gping --clear google.com
