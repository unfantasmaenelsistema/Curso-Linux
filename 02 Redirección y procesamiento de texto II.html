6. Comando cut (Cortar)

El comando cut se utiliza para extraer secciones o columnas de cada línea de un archivo. Es fundamental para trabajar con archivos de datos delimitados (como CSV).

Opción Común Descripción
-d 'DELIMITADOR' Especifica el carácter delimitador de campos (ej: ,, , |).
-f LISTA_CAMPOS Especifica los campos (columnas) a cortar. Puede ser un solo número (ej: 2), un rango (ej: 1-3), o una lista separada por comas (ej: 1,5).

Ejemplos Prácticos con cut

Tarea Comando Ejecutado por jose Resultado y Explicación
Extraer nombres y ciudades cut -d ',' -f 1,5 datos_ventas.csv Extrae el primer campo (Nombre) y el quinto campo (Ciudad), usando la coma (,) como delimitador.
Extraer precios cut -d ',' -f 4 datos_ventas.csv Muestra solo los valores de la columna Precio.
Extraer desde el campo 3 en adelante cut -d ',' -f 3- datos_ventas.csv Muestra los campos Cantidad, Precio y Ciudad.

7. Comando sort (Ordenar)

El comando sort ordena las líneas de un archivo de texto. Por defecto, ordena alfabéticamente (orden lexicográfico).

Opción Común Descripción
-r Ordena en orden inverso (descendente).
-n Ordena por el valor numérico de la línea o campo.
-k N Ordena por el campo (columna) número N. Requiere usar -t si el archivo no está separado por espacios.
-t 'DELIMITADOR' Especifica el delimitador de campos.

Ejemplos Prácticos con sort

Tarea Comando Ejecutado por jose Resultado y Explicación
Ordenar alfabéticamente (por defecto) sort lista_productos.txt Ordena las líneas de lista_productos.txt alfabéticamente (A-Z).
Ordenar por Precio (numérico) sort -t ',' -k 4 -n datos_ventas.csv Ordena el archivo datos_ventas.csv numéricamente (-n) basándose en el campo 4 (-k 4), usando la coma como separador (-t ',').
Ordenar por Nombre (inverso) sort -t ',' -k 1 -r datos_ventas.csv Ordena por el campo 1 (Nombre) en orden alfabético inverso (Z-A).

8. Comando uniq (Único)

El comando uniq filtra o reporta líneas repetidas en un archivo. Importante: uniq solo detecta y opera sobre líneas que son idénticas y están adyacentes (juntas). Por lo tanto, casi siempre se usa inmediatamente después de sort.

Opción Común Descripción
-c Cuenta el número de ocurrencias de cada línea única.
-d Muestra solo las líneas que están duplicadas.
-u Muestra solo las líneas que son únicas (no se repiten).

Ejemplos Prácticos con uniq

Tarea Comando Ejecutado por jose Resultado y Explicación
Mostrar productos únicos sort lista_productos.txt | uniq Primero ordena el archivo para agrupar duplicados, luego uniq muestra solo una instancia de cada producto (Laptop, Mouse, Teclado, Monitor).
Contar ocurrencias sort lista_productos.txt | uniq -c Muestra el recuento de cuántas veces aparece cada producto único.
Listar solo los duplicados sort lista_productos.txt | uniq -d Muestra solo los productos que se repiten (Laptop, Mouse, Teclado).

9. Comando wc (Word Count)

El comando wc se utiliza para contar el número de líneas, palabras y caracteres/bytes de un archivo. Es útil para obtener métricas rápidas de los archivos.

Opción Común Descripción
-l Muestra solo el número de líneas.
-w Muestra solo el número de palabras.
-c Muestra solo el número de bytes (caracteres).

Ejemplos Prácticos con wc

Tarea Comando Ejecutado por jose Resultado y Explicación
Contar líneas, palabras y bytes wc datos_ventas.csv Muestra las tres estadísticas (líneas, palabras, bytes) para el archivo datos_ventas.csv.
Contar solo el número de líneas wc -l lista_productos.txt Muestra que el archivo tiene 8 líneas.
Contar palabras en una columna cut -d ',' -f 2 datos_ventas.csv | wc -w Extrae la columna de productos y luego cuenta cuántas "palabras" (productos) hay en esa lista (incluyendo la cabecera).

10. Comando tee (T de tubería)

El comando tee lee la entrada estándar y la escribe tanto a la salida estándar (pantalla) como a uno o más archivos simultáneamente. Su nombre viene de la forma de la letra 'T', ya que divide el flujo de datos.

Opción Común Descripción
-a Añade la salida al archivo en lugar de sobrescribirlo (por defecto, sobrescribe).

Ejemplos Prácticos con tee

Tarea Comando Ejecutado por jose Resultado y Explicación
Guardar y mostrar simultáneamente cat informe.log | tee salida_cat.txt Muestra el contenido de informe.log en la pantalla Y lo guarda en salida_cat.txt (sobrescribiendo el archivo si existe).
Añadir al archivo y mostrar echo "Tarea finalizada con éxito." | tee -a informe.log Muestra el mensaje en la pantalla Y añade (-a) el mensaje al final de informe.log.
Guardar resultado de un comando head -n 5 informe.log | tee primeras_lineas.txt Muestra las primeras 5 líneas en la pantalla Y guarda esas mismas 5 líneas en el archivo primeras_lineas.txt.

Ejercicios:

Guía práctica: Manipulación y análisis de texto en Linux

Usuario: jose
Sistema operativo: Ubuntu 24.04
Ruta base: /home/jose/documentos/

1. Comando cut — Extraer columnas o secciones de texto

El comando cut sirve para extraer columnas o fragmentos específicos de texto de un archivo o de la salida de otro comando.

Sintaxis

cut [opciones] [archivo]

Opciones más comunes

Opción Descripción
-d Define el delimitador (por defecto es tabulador).
-f Indica el campo o columna a mostrar.
-c Extrae caracteres específicos por posición.

Ejemplos prácticos

1.1. Extraer la primera columna de un archivo CSV

Supón que tienes usuarios.csv:

cat << EOF > /home/jose/Documentos/usuarios.csv

nombre,correo,edad

Ana,ana@example.com,28

José,jose@example.com,33

Laura,laura@example.com,25

EOF

cut -d ',' -f 1 usuarios.csv

Muestra solo los nombres.

1.2. Extraer la segunda y tercera columna

cut -d ',' -f 2,3 usuarios.csv

Muestra el correo y la edad.

1.3. Extraer caracteres del 1 al 10 de cada línea

cut -c 1-10 notas.txt

Muestra los primeros 10 caracteres de cada línea.

1.4. Usar cut con la salida de otro comando

ls -l | cut -d ' ' -f 1,3,9

Extrae el tipo de archivo, propietario y nombre del archivo.

No nos muestra el nombre del archivo correctamente porque ls -l usa múltiples espacios (y a veces tabulaciones) como separadores, no solo uno.

Cuando usas cut -d ' ', le indicas que un único espacio es el delimitador, lo cual confunde a cut y resulta en la salida desordenada que ves. Los campos que estás seleccionando (1, 3, y 9) se están mezclando con la columna de tamaño (total) y las marcas de tiempo.

La Solución Correcta: Usar awk

Para analizar la salida de ls -l, que es inconsistente con sus espacios, la herramienta más robusta es awk, ya que trata cualquier secuencia de espacios como un único separador por defecto.

El comando correcto es:

ls -l | awk '{print $1, $3, $9}'

Comando/Argumento Propósito Columna de ls -l
ls -l Lista el contenido del directorio en formato largo.
| | Pasa la salida de ls -l a la entrada de awk.
awk Utiliza esta herramienta de procesamiento de texto.
'{print $1, $3, $9}' Le dice a awk que imprima los campos:
$1 El primer campo: Tipo de archivo y Permisos (-rw-rw-r--). 1
$3 El tercer campo: Propietario (jose). 3
$9 El noveno campo: Nombre del Archivo (ej: usuarios.csv). 9

2. Comando sort — Ordenar texto o datos

sort se usa para ordenar líneas de texto de un archivo o de la salida de otro comando. Es ideal para trabajar con listas o informes.

Sintaxis

sort [opciones] [archivo]

Opciones comunes

Opción Descripción
-r Orden inverso (descendente).
-n Orden numérico.
-k Especifica la columna de ordenación.
-u Elimina duplicados (como uniq).
-t Define el delimitador.

Ejemplos prácticos

cat << EOF > /home/jose/Documentos/nombres.txt

Ana

Pedro

Luis

María

Carlos

Sofía

Javier

Elena

EOF

2.1. Ordenar un archivo alfabéticamente

sort nombres.txt

2.2. Ordenar de forma inversa

sort -r nombres.txt

2.3. Ordenar por edad en un archivo CSV

Archivo usuarios.csv

sort -t ',' -k3 -n usuarios.csv

Ordena por la tercera columna (edad) de forma numérica.

2.4. Eliminar duplicados automáticamente

sort -u nombres.txt

3. Comando uniq — Eliminar líneas duplicadas

uniq se utiliza para filtrar líneas duplicadas consecutivas en un archivo ordenado.

Para que funcione correctamente, el archivo debe estar ordenado previamente (usa sort antes si no lo está).

Sintaxis

uniq [opciones] [archivo]

Opciones comunes

Opción Descripción
-c Muestra el número de repeticiones.
-d Muestra solo las líneas duplicadas.
-u Muestra solo las líneas únicas.

Ejemplos prácticos

cat << EOF > /home/jose/Documentos/frutas.txt

Manzana

Pera

Plátano

Manzana

Naranja

Kiwi

Fresa

Pera

Manzana

Mango

Naranja

EOF

3.1. Eliminar duplicados consecutivos

uniq frutas.txt

3.2. Contar cuántas veces se repite cada línea

uniq -c frutas.txt

Salida:

1 Fresa

2 Manzana

3 Pera

3.3. Combinar sort y uniq

sort frutas.txt | uniq

Elimina duplicados aunque no estén consecutivos.

3.4. Mostrar solo las líneas duplicadas consecutivas

uniq -d frutas.txt

4. Comando wc — Contar líneas, palabras y caracteres

wc (word count) sirve para contar líneas, palabras, caracteres o bytes de uno o varios archivos.

Sintaxis

wc [opciones] [archivo]

Opciones comunes

Opción Descripción
-l Cuenta líneas.
-w Cuenta palabras.
-c Cuenta bytes (tamaño).
-m Cuenta caracteres.

Ejemplos prácticos

4.1. Contar líneas, palabras y bytes de un archivo

wc notas.txt

Salida típica:

61 164 1344 notas.txt 12 líneas, 84 palabras, 560 bytes.

4.2. Contar solo las líneas

wc -l notas.txt

4.3. Contar palabras en varios archivos

wc -w *.txt

Muestra el conteo individual y el total.

4.4. Usar con otros comandos

ls | wc -l

Muestra cuántos archivos hay en el directorio actual.

5. Comando tee — Guardar y mostrar al mismo tiempo

tee permite guardar la salida de un comando en un archivo mientras la muestra por pantalla.
Es muy útil en tuberías (pipes).

Sintaxis

comando | tee [opciones] [archivo]

Opciones comunes

Opción Descripción
-a Añade (append) al final del archivo sin sobrescribirlo.

Ejemplos prácticos

5.1. Guardar la salida de un comando y mostrarla

ls -l | tee notas.txt

Muestra la lista de archivos y la guarda en notas.txt.

5.2. Añadir sin sobrescribir

df -h | tee -a nombres.txt

Añade el resultado del comando df -h al final de nombres.txt.

5.3. Usar tee con varios comandos encadenados

cat usuarios.csv | sort | tee ordenado.csv | wc -l

Ordena el archivo, guarda el resultado en ordenado.csv y muestra cuántas líneas tiene.

5.4. Guardar logs de ejecución

./script.sh | tee /home/jose/logs/ejecucion.log

Guarda la salida del script en un archivo de log y la muestra en pantalla.

Resumen

Comando Propósito principal Ejemplo típico
cut Extraer columnas o caracteres cut -d ',' -f 1 archivo.csv
sort Ordenar líneas sort -n archivo.txt
uniq Eliminar duplicados `sort archivo.txt
wc Contar líneas, palabras o bytes wc -l archivo.txt
tee Mostrar y guardar simultáneamente `ls
