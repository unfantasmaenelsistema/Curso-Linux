Clonado y Restauración de Discos Mediante Clonezilla y Servidor SSH

Esta guía detalla el proceso para utilizar Clonezilla para crear y restaurar imágenes de sistema, empleando un servidor Debian 11 configurado con SSH como punto de almacenamiento remoto.

1. Preparación del Servidor SSH (Debian 11)

El primer paso es configurar el servidor Debian que almacenará las imágenes.

Configuración Inicial y Usuarios

  1. Se instala una máquina virtual con Debian 11.

  2. Se crean los usuarios root y jose.

  3. El disco virtual principal para el sistema operativo es de unos 45GB.

Configuración de Almacenamiento Adicional

  1. Se añade un segundo disco virtual a la VM (casi 500GB), reservado dinámicamente, en la configuración de VirtualBox (pestaña Almacenamiento, controladores SATA).

  2. Después de actualizar Debian, se accede a la consola como root con sudo su o su root.

  3. Se instala el servicio SSH: apt-get install ssh.

  4. Se verifica que el disco de 500GB aparece como /dev/sdb con fdisk -l.

Particionado y Montaje del Disco de Imágenes

  1. El disco /dev/sdb no está formateado. Se crea la tabla de particiones con: fdisk /dev/sdb.

  2. En el prompt de fdisk, se responde n para crear una nueva partición.

  3. Se pone p para la partición primaria.

  4. Se pone 1 para crear una única partición (/dev/sdb1).

  5. Se usa w para salir y guardar los cambios.

  6. Se formatea la partición: mke2fs -t ext4 /dev/sdb1.

  7. Se navega a la carpeta home: cd /home.

  8. Se crea la carpeta de almacenamiento de imágenes: mkdir imagen.

  9. Se otorgan todos los permisos a la carpeta: chmod 777 imagen/.

  10. Se monta el disco duro en la carpeta: mount /dev/sdb1 /home/imagen/.

Montaje Automático y Configuración SSH

  1. Para el montaje automático en el arranque, se edita /etc/fstab: nano /etc/fstab.

  2. Se añade la línea al final del fichero: /dev/sdb1 /home/imagen ext4 errors remount -ro 0 0. Se guarda el fichero.

  3. Se edita el archivo de configuración del servidor SSH: nano /etc/ssh/sshd_config.

  4. Te aseguras de que las siguientes líneas estén configuradas:

    • Port 22

    • Protocol 2

    • PermitRootLogin no (cambiado de without-password)

    • Se añade: AllowUsers jose

  5. Se edita el archivo de configuración del cliente SSH: nano /etc/ssh/ssh_config.

  6. Se descomentan las líneas:

    • PasswordAuthentication yes

    • Port 22

    • Protocol 2

  7. Se reinicia el servicio SSH: /etc/init.d/ssh restart.

  8. Se comprueba el estado: /etc/init.d/ssh status.

  9. Se obtiene la IP del servidor para la conexión.

2. Creación de la Imagen (Clonezilla)

Se utiliza Clonezilla en el equipo de origen para crear la imagen y guardarla en el servidor SSH.

  1. Se arranca el equipo de origen con el pendrive booteable de Clonezilla.

  2. Se selecciona Idioma español.

  3. Se elige no tocar el mapa del teclado.

  4. Se selecciona Iniciar Clonezilla.

  5. Se elige la opción Disco/Partición a/desde imagen.

  6. Se escoge usar un Servidor SSH.

  7. En Modo de red, se elige Usar transmisión DHCP o Usar IP estática (con la IP de Debian).

  8. Se introduce la IP de la máquina Debian (servidor SSH).

  9. El Puerto es 22.

  10. El usuario es jose.

  11. La ruta de almacenamiento es /home/imagen.

  12. Se confirma que es correcto.

  13. Se introduce la contraseña del usuario jose.

  14. Se pulsa Intro para continuar.

  15. Se elige modo principiante.

  16. Se escoge salvar imagen. (Esto crea una imagen del tamaño que realmente ocupa el sistema).

  17. Se cambia el nombre de la imagen para facilitar la identificación.

  18. Se selecciona el disco de origen, asegurándose de dejar marcado el asterisco.

  19. Se elige realizar comprobaciones (si), aunque tarde más.

  20. Se elige que compruebe la imagen grabada.

  21. Se elige no cifrar la imagen.

  22. Se deja la última opción por defecto (para que pregunte qué hacer al terminar).

  23. Se pulsa Intro.

  24. Se confirma con yes.

  25. Comienza el clonado.

  26. Al finalizar, se elige Apagar.

3. Restauración de la Imagen (Clonezilla)

Se utiliza Clonezilla en el equipo de destino para restaurar la imagen guardada en el servidor SSH.

  1. Se arranca el equipo de destino con el pendrive booteable de Clonezilla.

  2. Se selecciona Idioma español.

  3. Se elige no tocar el mapa del teclado.

  4. Se selecciona Iniciar Clonezilla.

  5. Se elige la opción Disco/Partición a/desde imagen.

  6. Se escoge usar un Servidor SSH.

  7. En Modo de red, se elige Usar transmisión DHCP o Usar IP estática.

  8. Se introduce la IP de la máquina Debian (servidor SSH).

  9. El Puerto es 22.

  10. El usuario es jose.

  11. La ruta donde está la imagen es /home/imagen.

  12. Se confirma que es correcto.

  13. Se introduce la contraseña del usuario jose.

  14. Se pulsa Intro para continuar.

  15. Se elige modo principiante.

  16. Se elige la tercera opción: restaurar imagen a disco local.

  17. Se escoge la imagen a restaurar.

  18. Aparece el disco de destino (la máquina donde se va a restaurar).

  19. Se elige si se desea o no realizar comprobaciones.

  20. Se espera a que termine el proceso de restauración.
