11. Comando grep (Global Regular Expression Print)

grep es la herramienta fundamental para buscar texto o patrones (Expresiones Regulares) dentro de archivos y mostrar las líneas que coinciden.

Opción Común Descripción
-i Ignora mayúsculas/minúsculas en la búsqueda.
-v Invierte la coincidencia; muestra las líneas que NO coinciden con el patrón.
-n Muestra el número de línea donde se encontró la coincidencia.
-c Muestra solo el conteo del número de líneas coincidentes.

Ejemplos Prácticos con grep

Tarea Comando Ejecutado por jose Resultado y Explicación
Buscar errores grep "ERROR" informe.log Muestra solo la línea 5, ya que contiene el texto exacto "ERROR".
Buscar sesiones sin distinguir mayúsculas grep -i "usuario" informe.log Muestra las líneas 11 y 12, ya que busca "usuario" sin importar mayúsculas/minúsculas.
Contar líneas que NO son de inicio de sesión grep -v "ha iniciado sesión" informe.log | wc -l Muestra todas las líneas que no contienen la frase de inicio de sesión, y luego wc -l cuenta cuántas líneas son.
Mostrar errores con número de línea grep -n "ERROR" informe.log Muestra: 5:[ERROR] Fallo al escribir en disco: Permiso denegado.

12. Comando sed (Stream Editor)

sed es un editor de flujo de texto. Se utiliza principalmente para sustituir texto o eliminar líneas de un archivo. A diferencia de un editor de texto normal, sed no modifica el archivo original por defecto, sino que opera sobre el flujo de datos.

Comando Común Descripción
s/patrón/reemplazo/g El comando de sustitución (s). Reemplaza el patrón por el reemplazo. La g indica reemplazo global (todas las ocurrencias en la línea).
d Comando de borrado (delete).
-i Modifica el archivo original (¡Usar con precaución!).

Ejemplos Prácticos con sed

Tarea Comando Ejecutado por jose Resultado y Explicación
Reemplazar 'Usuario' por 'User' sed 's/Usuario/User/g' informe.log Muestra todo el log, pero las líneas 11 y 12 dirán: "User 'maria' ha iniciado sesión."
Eliminar líneas de error sed '/ERROR/d' informe.log Muestra todo el log, excepto la línea 5 que contenía "[ERROR]".
Modificar el archivo (usando -i) sed -i 's/ha iniciado sesión/logged in/g' informe.log ¡Cuidado! Esto cambia las líneas 11 y 12 permanentemente en el archivo informe.log.

13. Comando awk

awk es un lenguaje de programación y herramienta de procesamiento de texto increíblemente potente, ideal para analizar datos columnares (por campos) y realizar cálculos o formateo complejo. Trabaja línea por línea y campo por campo.

Variables Internas Clave Descripción
\$0 Representa toda la línea actual.
\$1, \$2, \$3, ... Representan el campo 1, 2, 3, etc., de la línea actual.
FS Field Separator (Separador de Campo). Por defecto es el espacio/tabulador.
NR Number of Record (Número de línea).

Ejemplos Prácticos con awk

Tarea Comando Ejecutado por jose Resultado y Explicación
Mostrar sólo las líneas que contienen 'CPU' o 'RAM' awk '/CPU|RAM/' informe.log
Extraer y formatear nombres de usuario grep "sesión" informe.log | awk '{print "Bienvenido:", $2}' 1. grep filtra las líneas de inicio de sesión. 2. awk procesa estas líneas; $2 (el segundo campo) es el nombre de usuario (ej: 'maria'). El separador de campos por defecto es el espacio.
Simular un cálculo de uso echo "CPU: 45%" | awk '{print "El uso fue de:", $2}' Demuestra el acceso a campos. Si la entrada es "CPU: 45%", el segundo campo ($2) es "45%".

14. Comando tr (Translate or Delete Characters)

El comando tr se utiliza para traducir (reemplazar) o eliminar caracteres individuales de la entrada de datos. Solo funciona con la entrada estándar (STDOUT), por lo que siempre se utiliza con una tubería (|).

Opción Común Descripción
-d Elimina los caracteres especificados.

Ejemplos Prácticos con tr

Tarea Comando Ejecutado por jose Resultado y Explicación
Convertir a mayúsculas cat informe.log | tr 'a-z' 'A-Z' Muestra todo el contenido del archivo en letras mayúsculas.
Eliminar caracteres no deseados cat informe.log | tr -d '()' Muestra el log, eliminando todos los paréntesis ( y ) (ej: en (backup.sh)).
Reemplazar espacios por guiones echo "Hola mundo Linux" | tr ' ' '-' Muestra: Hola-mundo-Linux.

15. Comando xargs (Execute Arguments)

El comando xargs toma la entrada de datos (líneas o elementos separados por espacios) que recibe por la tubería (|) y la usa como argumentos para ejecutar otro comando. Es crucial cuando un comando genera una lista de elementos (ej: nombres de archivo) y necesitas pasar esa lista a un segundo comando.

Opción Común Descripción
-I {} Indica que se reemplace el placeholder {} por cada línea de entrada. Útil para comandos que solo aceptan un argumento a la vez.
-n 1 Ejecuta el comando una vez por cada línea de entrada.

Ejemplos Prácticos con xargs

Tarea Comando Ejecutado por jose Resultado y Explicación
Eliminar archivos encontrados find /tmp/jose -name "*.tmp" | xargs rm 1. find busca todos los archivos .tmp en /tmp/jose. 2. Pasa la lista de archivos encontrados a xargs. 3. xargs ejecuta el comando rm (eliminar) usando esa lista como argumentos.
Ejecutar un comando por cada línea ls archivos* | xargs -n 1 echo "Procesando:" 1. ls lista los archivos que coinciden con el patrón. 2. xargs -n 1 ejecuta echo "Procesando:" una vez por cada archivo listado.
Copiar archivos a un nuevo destino find . -name "*.conf" | xargs -I {} cp {} /home/jose/config_backup/ 1. find busca todos los archivos .conf. 2. xargs -I {} indica que por cada archivo encontrado, se ejecute cp y se reemplace {} con el nombre del archivo, copiándolo al directorio de backup.

1. Comando grep — Buscar texto en archivos

grep (Global Regular Expression Print) busca patrones o palabras dentro de archivos o salidas de comandos.
Es uno de los comandos más usados para filtrar información.

Sintaxis

grep [opciones] 'patrón' [archivo]

Opciones comunes

Opción Descripción
-i Ignora mayúsculas/minúsculas.
-n Muestra el número de línea.
-v Muestra las líneas que no coinciden.
-r Busca de forma recursiva en directorios.
-l Muestra solo los nombres de archivos coincidentes.
-c Cuenta cuántas coincidencias hay.
-E Usa expresiones regulares extendidas.

Ejemplos prácticos

1.1. Buscar una palabra en un archivo

grep "error" /var/log/syslog

Muestra las líneas que contienen “error”.

1.2. Buscar sin distinguir mayúsculas

cat << EOF > /home/jose/Documentos/info.txt

Resumen del Sistema Operativo

-----------------------------

Esta es la primera sección de información.

El servidor utiliza la distribución

linux **ubuntu** 24.04 para sus operaciones.

Es una plataforma estable.

La configuración de red fue probada en **UBUNTU**.

Otros sistemas operativos no están permitidos.

Fin del resumen.

EOF

grep -i "ubuntu" info.txt

1.3. Mostrar el número de línea

grep -n "nombre" /home/jose/Documentos/usuarios.csv

1.4. Buscar en todos los archivos de un directorio

grep -r "jose" /home/jose/Documentos/

1.5. Contar coincidencias

grep -c "login" /var/log/auth.log

1.6. Excluir líneas que contengan un texto

grep -v "root" /etc/passwd

1.7. Buscar usando expresiones regulares

grep -E "^[A-Z]" nombres.txt

Muestra las líneas que comienzan con una letra mayúscula.

2. Comando sed — Editor de texto por flujo (stream editor)

sed permite editar texto sin abrirlo, haciendo sustituciones, eliminaciones o inserciones sobre la marcha.

Sintaxis

sed [opciones] 'expresión' [archivo]

Opciones comunes

Opción Descripción
-n Suprime la salida automática.
-e Permite usar varias expresiones.
-i Edita el archivo directamente (in place).

Ejemplos prácticos

2.1. Reemplazar una palabra (solo muestra el resultado)

echo -e "Inicio de sesión con error.\nerror crítico en el sistema de error.\nNo hay errores.\nEste es un error. Este es otro error." > reporte.txt

sed 's/error/éxito/' reporte.txt

Reemplaza la primera aparición de “error” por “éxito” en cada línea.

2.2. Reemplazar todas las apariciones en cada línea

sed 's/error/éxito/g' reporte.txt

2.3. Modificar directamente el archivo

echo -e "Tarea 1: pendiente, prioritaria.\nTarea 2: pendiente, revisar el estado pendiente del reporte.\nTarea 3: completado.\nTarea 4: pendiente." > tareas.txt

sed -i 's/pendiente/completado/g' tareas.txt

Cambia “pendiente” por “completado” dentro del archivo real.

2.4. Eliminar líneas que contengan un patrón

sed '/DEBUG/d' log.txt

El comando sed '/DEBUG/d' log.txt es una forma rápida y común de eliminar líneas que contienen una palabra o patrón específico de un archivo, sin modificar el archivo original.

Parte Nombre Significado
sed Stream Editor Es una herramienta de procesamiento de texto que funciona línea por línea.
'...' Patrón y Acción La acción a realizar, encerrada en comillas simples.
/DEBUG/ Patrón de Búsqueda Una expresión regular que selecciona todas las líneas que contengan la palabra DEBUG. Las barras diagonales (/ /) delimitan el patrón.
d Comando de Eliminación Es la acción (delete) que se aplica a las líneas seleccionadas por el patrón. Le dice a sed que elimine la línea actual del flujo de salida.
log.txt Archivo de Entrada El archivo cuyo contenido se va a procesar.

¿Qué hace el comando?

El comando completo le indica a sed:

"Toma cada línea del archivo log.txt y, si esa línea contiene la palabra DEBUG (en mayúsculas), elimínala (d). Luego, imprime todas las líneas restantes en la salida estándar (la terminal)."

Puntos Clave:

  1. Eliminación Selectiva: Solo se eliminan las líneas que coinciden con el patrón /DEBUG/.

  2. No Modifica el Archivo Original: sed por defecto imprime el resultado en la terminal (stdout). El archivo log.txt no se modifica.

  3. Distinción de Mayúsculas/Minúsculas: El patrón /DEBUG/ solo eliminará líneas que contengan DEBUG; no eliminará líneas que contengan Debug o debug.

echo -e "[2025-10-10 08:00:01] INFO: Inicio de proceso.\n[2025-10-10 08:00:05] DEBUG: Variable X es igual a 5.\n[2025-10-10 08:00:10] WARN: Conexión lenta detectada.\n[2025-10-10 08:00:12] DEBUG: El usuario A accedió a la base de datos.\n[2025-10-10 08:00:15] ERROR: Fallo al cargar módulo.\nEsta línea no tiene etiqueta, pero sí la palabra DEBUG.\n[2025-10-10 08:00:20] INFO: Fin de proceso." > log.txt

El comando sed '/DEBUG/d' log.txt es muy útil para la limpieza de archivos de registro. Lo que hace es:

  • Busca cualquier línea en el archivo log.txt que contenga el patrón "DEBUG".

  • La acción d (de delete) elimina esa línea.

  • El resultado (el log sin las líneas DEBUG) se muestra en la salida estándar (la terminal), sin modificar el archivo original.

sed '/DEBUG/d' log.txt

Las tres líneas que contienen la palabra "DEBUG" (sin importar su posición) habrán sido eliminadas de la salida:

[2025-10-10 08:00:01] INFO: Inicio de proceso.

[2025-10-10 08:00:10] WARN: Conexión lenta detectada.

[2025-10-10 08:00:15] ERROR: Fallo al cargar módulo.

[2025-10-10 08:00:20] INFO: Fin de proceso.

2.5. Mostrar solo líneas específicas

sed -n '1,5p' notas.txt

Muestra solo las líneas 1 a 5.

2.6. Añadir texto antes o después de una línea

echo -e 'Sección 1\nTítulo Principal del Documento\nEste párrafo pertenece al título principal.\nTítulo Secundario\nOtro párrafo sin título.\nTítulo final (¡con paréntesis!)' > documento.txt

sed '/Título/a Subtítulo agregado' documento.txt

Inserta “Subtítulo agregado” después de la línea que contiene “Título”.

3. Comando awk — Procesamiento y análisis de texto por columnas

awk es un lenguaje de procesamiento de texto diseñado para analizar y manipular datos estructurados (como CSV o tablas).

Sintaxis

awk 'patrón { acción }' [archivo]

Ejemplos prácticos

Supón que tienes el archivo ventas.txt:

Producto Precio Cantidad

Manzanas 2.5 10

Peras 3.0 5

Bananas 1.8 12

echo -e 'Producto Precio Cantidad\nManzanas 2.5 10\nPeras 3.0 5\nBananas 1.8 12' > ventas.txt

3.1. Mostrar una columna específica

awk '{print $1}' ventas.txt

Muestra solo la columna de productos.

3.2. Mostrar varias columnas

awk '{print $1, $2}' ventas.txt

Producto y precio.

3.3. Calcular totales

awk '{total = $2 * $3; print $1, total}' ventas.txt

Muestra el producto y el total de cada línea.

3.4. Mostrar solo filas que cumplan una condición

awk '$2 > 2 {print $1, $2}' ventas.txt

Muestra productos con precio mayor que 2.

3.5. Calcular sumas o promedios

awk '{suma += $2 * $3} END {print "Total general:", suma}' ventas.txt

3.6. Usar delimitadores personalizados

echo -e 'Nombre,Apellido,Edad,Ciudad\nJuan,Perez,20,Madrid\nMaria,Gomez,22,Barcelona\nCarlos,Lopez,19,Sevilla\nAna,Ruiz,21,Valencia' > alumnos.csv

awk -F ',' '{print $1, $3}' alumnos.csv

Indica que el delimitador es una coma.

4. Comando tr — Traducir o eliminar caracteres

tr (translate) se usa para reemplazar, eliminar o convertir caracteres en la entrada estándar.

No opera directamente sobre archivos, sino sobre flujos de texto (usando redirección o tuberías).

Sintaxis

tr [opciones] SET1 [SET2]

Opciones comunes

Opción Descripción
-d Elimina caracteres.
-s Sustituye repeticiones consecutivas por una sola.

Ejemplos prácticos

echo -e 'este es un texto de pRueba.\ntiene muchas vocales\ny también espacios múltiples.' > texto.txt

4.1. Convertir texto a mayúsculas

cat texto.txt | tr 'a-z' 'A-Z'

4.2. Convertir a minúsculas

echo "HOLA MUNDO" | tr 'A-Z' 'a-z'

4.3. Eliminar caracteres específicos

cat texto.txt | tr -d 'aeiou'

Elimina todas las vocales.

4.4. Reemplazar espacios por guiones

echo "curso linux basico" | tr ' ' '-'

Resultado: curso-linux-basico

4.5. Comprimir múltiples espacios en uno solo

cat texto.txt | tr -s ' '

5. Comando xargs — Construir y ejecutar comandos a partir de entradas

xargs toma una lista de elementos de la entrada estándar y los pasa como argumentos a otro comando.
Es ideal cuando un comando no acepta entrada por tubería directamente.

Sintaxis

xargs [comando] [opciones]

Ejemplos prácticos

5.1. Eliminar varios archivos listados

ls *.log | xargs rm

Borra todos los archivos .log listados.

5.2. Buscar y eliminar archivos específicos

find . -name "*.bak" | xargs rm

5.3. Contar líneas de varios archivos

ls *.txt | xargs wc -l

5.4. Copiar varios archivos a otro directorio

find . -name "*.txt" | xargs -I {} cp {} /home/jose/backup/

Usa {} como marcador de posición para cada archivo encontrado.

5.5. Combinar con grep

grep -rl "ERROR" /var/log | xargs cat

Muestra el contenido de todos los archivos que contienen “ERROR”.

sudo grep -rl "ERROR" /var/log | xargs sudo cat

Resumen

Comando Función principal Ejemplo típico
grep Buscar texto o patrones grep "error" log.txt
sed Sustituir o eliminar texto sed 's/viejo/nuevo/g' archivo.txt
awk Procesar columnas y cálculos awk '{print $1, $2*$3}' datos.txt
tr Convertir o eliminar caracteres tr 'a-z' 'A-Z'
xargs Ejecutar comandos sobre listas `find . -name "*.log"

Ejercicio práctico sugerido

Crea el archivo datos.csv:

cat > datos.csv

Ana,25

Luis,32

Marta,29

Jose,32

Ctrl+D

Mostrar solo los nombres:

cut -d ',' -f 1 datos.csv

Filtrar los que tienen “32”:

grep "32" datos.csv

Reemplazar las comas por tabulaciones:

cat datos.csv | tr ',' '\t'

Calcular promedio de edad:

awk -F ',' '{suma+=$2} END {print "Promedio:", suma/NR}' datos.csv

Guardar el resultado y mostrarlo:

awk -F ',' '{suma+=$2} END {print "Promedio:", suma/NR}' datos.csv | tee resumen.txt
