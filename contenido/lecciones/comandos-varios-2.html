comandos de conversión de ficheros

Nota Importante: Estos comandos requieren que estén instalados. En Ubuntu, dos2unix viene en su propio paquete y recode también. Si recibes un error de "comando no encontrado", puedes instalarlos con:

sudo apt update
sudo apt install dos2unix recode

dos2unix - Conversión de Ficheros de DOS a UNIX

El comando dos2unix elimina los caracteres de retorno de carro (\r o CR) que se utilizan al final de cada línea en los archivos de texto de Windows/MS-DOS. En Linux/UNIX, solo se utiliza el salto de línea (\n o LF).

Comando/SintaxisDescripción
dos2unix <fichero_entrada> <fichero_salida>Convierte el fichero de entrada y guarda el resultado en un nuevo fichero de salida.
dos2unix <fichero>Convierte el fichero en el mismo sitio (sobrescribe el original).

Ejemplos Prácticos

  1. Crear un fichero con formato DOS (Simulación):

Para que el ejemplo sea práctico, primero simulamos un archivo de DOS/Windows (los archivos creados con nano en Linux tienen formato UNIX por defecto, por lo que lo modificamos para el ejemplo):

# Creamos un archivo de texto
echo "Linea 1" > filedos.txt
echo "Linea 2" >> filedos.txt
# Añadimos los caracteres de retorno de carro para simular el formato DOS

# (Esto es una forma avanzada de simular el formato CR-LF de DOS)

sed -i 's/$/\r/' filedos.txt
cat filedos.txt

No muestra esos caracteres, pero los podemos ver con:

cat -A filedos.txt

El comando cat en Linux está diseñado para ignorar o no mostrar explícitamente el carácter de Retorno de Carro (\r) cuando se encuentra en un archivo de texto.

¿Por qué cat no lo muestra?

En los sistemas Unix (Linux, macOS):

  • El fin de línea es solo el carácter Nueva Línea (LF o \n).
  • El carácter Retorno de Carro (CR o \r) no es considerado parte del final de línea; su propósito histórico es mover el cursor al inicio de la línea.

Cuando cat encuentra el patrón de final de línea de DOS/Windows (\r\n), simplemente procesa el \r (Retorno de Carro) como un carácter que no se imprime y luego salta a la nueva línea con el \n (Nueva Línea). Visualmente, el archivo se ve idéntico al formato Unix original, ocultando el \r.

Cómo confirmar que el \r está ahí

Para demostrar que el carácter \r fue añadido por sed, puedes usar un comando que esté diseñado para mostrar caracteres no imprimibles o que muestre los archivos en formato hexadecimal.

1. Usando el comando cat -A (o -vET)

La opción -A del comando cat (que equivale a -vET) fuerza la visualización de caracteres especiales.

cat -A filedos.txt

Resultado esperado:

Linea 1^M$

Linea 2^M$

  • ^M: Es la representación visible del carácter Retorno de Carro (\r).
  • $: Es la representación visible del carácter Nueva Línea (\n) (gracias a la opción -E).
2. Usando el comando od (Octal Dump)

Este comando muestra el contenido del archivo en formato octal o hexadecimal, revelando los códigos de los caracteres:

od -c filedos.txt

Resultado esperado (parcial):

Parte del archivoFormato Unix originalDespués del sed (Formato DOS)
Fin de línea\n (Código octal: \012)\r\n (Código octal: \015\012)

Si ejecutas od -c filedos.txt, verás el código \r (\015) antes de cada código \n (\012), confirmando que la acción de sed fue exitosa.

  1. Convertir un fichero de MSDOS a UNIX (guardando en un nuevo fichero):
dos2unix -n filedos.txt fileunix.txt

Resultado: El archivo fileunix.txt ahora tendrá el formato de línea correcto para UNIX. El archivo original filedos.txt permanece sin cambios.

  1. Convertir y sobrescribir el fichero original (uso más común):
dos2unix filedos.txt

Resultado: El archivo filedos.txt se convierte a formato UNIX.

unix2dos - Conversión de Ficheros de UNIX a DOS

El comando unix2dos hace la operación inversa: añade los caracteres de retorno de carro (\r o CR) antes de cada salto de línea, creando un archivo con el formato de terminación de línea (CR-LF) esperado por los sistemas Windows/MS-DOS.

Comando/SintaxisDescripción
unix2dos <fichero_entrada> <fichero_salida>Convierte el fichero de entrada y guarda el resultado en un nuevo fichero de salida.
unix2dos <fichero>Convierte el fichero en el mismo sitio (sobrescribe el original).

Ejemplos Prácticos

  1. Crear un fichero con formato UNIX (Formato predeterminado en Ubuntu):
echo "Este archivo esta en formato UNIX." > fileunix.txt
  1. Convertir un fichero de UNIX a MSDOS (guardando en un nuevo fichero):
unix2dos -n fileunix.txt filedos.txt
cat -A filedos.txt

Resultado: El archivo filedos.txt ahora contiene la secuencia CR-LF al final de cada línea, haciéndolo compatible con editores de texto antiguos de DOS/Windows.

recode - Conversión de Codificación y Formato General

El comando recode es una herramienta muy potente y versátil para convertir la codificación de caracteres (p. ej., ISO-8859-1 a UTF-8) y realizar conversiones de formato de texto, como de texto plano a HTML.

sudo apt install recode

Opciones Comunes

OpciónDescripción
<codificación_origen>..<codificación_destino>Especifica el tipo de conversión a realizar.
-lLista todas las conversiones de codificación y formato disponibles.
< / >Se utilizan para redirigir la entrada y salida, ya que recode procesa la entrada estándar por defecto.

Ejemplos Prácticos

  1. Mostrar todas las conversiones de formato disponibles (recode -l | more):

Este comando es esencial para saber qué tipos de conversión soporta recode (codificaciones como utf8, latin1, y formatos como html, latex, dos, etc.).

recode -l | more

Usa la tecla Espacio para avanzar una página o q para salir.

  1. Convertir un fichero de texto a HTML (recode ..HTML):

Se requiere que el archivo de texto se pase como entrada (<) y el resultado se capture como salida (>).

# 1. Crear el fichero de texto
echo "Este es el titulo" > page.txt
echo "" >> page.txt
echo "Contenido de la pagina." >> page.txt
# 2. Realizar la conversión
recode ..HTML < page.txt > page.html

Resultado: El archivo page.html contendrá ahora el texto original rodeado de etiquetas HTML básicas (<title>, <body>, etc.).

  1. Convertir la codificación de caracteres:

Cambia la codificación del archivo de ISO-8859-1 (latin1) a la moderna UTF-8.

recode latin1..utf8 mi_fichero.txt
# Paso 1: Crea el archivo temporal con caracteres especiales.
echo "El camión de Jose mañana." > archivo_latin1.txt

# Paso 2: Usa iconv para forzar la codificación a ISO-8859-1 (Latin-1). Esto asegura que el archivo de entrada esté en la codificación correcta para la prueba.

iconv -f UTF-8 -t ISO-8859-1 archivo_latin1.txt > archivo_latin1_final.txt
# Limpia el archivo temporal
rm archivo_latin1.txt
# Ahora, el archivo a convertir es 'archivo_latin1_final.txt'

3. Ejecutar la Conversión con recode

Ahora, ejecuta el comando usando el archivo que acabamos de crear. recode realiza la conversión in-place (sobrescribe el archivo original por defecto).

recode latin1..utf8 archivo_latin1_final.txt
  • Resultado Esperado: El comando se ejecuta sin mostrar salida (si es exitoso). El archivo archivo_latin1_final.txt ha sido sobrescrito con el mismo contenido, pero ahora codificado en UTF-8.

4. Verificar la Codificación

Puedes usar el comando file para confirmar que la codificación del archivo ha cambiado:

file archivo_latin1_final.txt

Salida Esperada (después de la conversión):

archivo_latin1_final.txt: UTF-8 Unicode text

Comandos de apagado, reinicio y cierre de sesión

Nota Importante: Todos los comandos de apagado y reinicio del sistema requieren permisos de administrador (sudo), ya que afectan a todos los usuarios y al estado completo de la máquina.

I. Comandos de Apagado del Sistema (Halt)

Estos comandos detienen el sistema operativo de forma segura y cortan la alimentación eléctrica.

ComandoDescripciónRequisitos
shutdown -h nowApagado inmediato (-h de halt, now de inmediato). Es el método preferido y más moderno.sudo
haltUn comando simple que ejecuta un apagado inmediato. Equivalente a shutdown -h now.sudo
init 0Cambia al nivel de ejecución (runlevel) 0, que está definido para apagar el sistema.sudo
telinit 0Es un enlace simbólico a init 0, por lo que tiene el mismo efecto: apagar el sistema.sudo

Ejemplos Prácticos

  1. Apagar el sistema inmediatamente (Método recomendado):
sudo shutdown -h now
  1. Apagar el sistema inmediatamente (Alternativa simple):
sudo halt
  1. Apagar el sistema usando el nivel de ejecución 0 (Método tradicional):
sudo init 0

II. Apagado Planificado y Cancelación

El comando shutdown permite planificar el apagado del sistema para un momento futuro o un intervalo de tiempo, y cancelarlo si es necesario.

ComandoDescripciónRequisitos
shutdown -h hours:minutes &Apagado planificado a una hora específica (por ejemplo, 17:30). El & hace que el comando se ejecute en segundo plano.sudo
shutdown -h +minutesApagado planificado en X minutos.sudo
shutdown -cCancela cualquier apagado planificado.sudo

Ejemplos Prácticos

  1. Apagar el sistema a las 17:00 de hoy (Hora absoluta):

El sistema envía una advertencia a todos los usuarios conectados.

sudo shutdown -h 17:00
  1. Planificar un apagado en 30 minutos, con un mensaje para los usuarios:
sudo shutdown -h +30 "El servidor se apagará en 30 minutos para mantenimiento."
  1. Cancelar el apagado planificado:

Si te arrepientes o terminas el trabajo antes de tiempo.

sudo shutdown -c

III. Comandos de Reinicio del Sistema (Reboot)

Estos comandos detienen el sistema de forma segura y luego lo reinician inmediatamente.

ComandoDescripciónRequisitos
shutdown -r nowReinicio inmediato (-r de reboot). Es el método recomendado.sudo
rebootUn comando simple que ejecuta un reinicio inmediato. Equivalente a shutdown -r now.sudo
init 6Cambia al nivel de ejecución (runlevel) 6, que está definido para reiniciar el sistema.sudo

Ejemplos Prácticos

  1. Reiniciar el sistema inmediatamente (Método recomendado):
sudo shutdown -r now
  1. Reiniciar el sistema inmediatamente (Alternativa simple):
sudo reboot
  1. Reiniciar el sistema usando el nivel de ejecución 6 (Método tradicional):
sudo init 6

Este comando no apaga la máquina; solo cierra la sesión actual del usuario.

ComandoDescripciónRequisitos

Si estás en una sesión SSH o en una terminal de consola.

logout

Alternativamente, puedes usar Ctrl + D para lograr el mismo resultado.

El comando grep (Global Regular Expression Print)

Para practicar, primero crearemos dos archivos de ejemplo en el directorio de jose:

  1. documento.txt: Un archivo de texto simple.
  2. logs.log: Un archivo que simula registros del sistema.
echo "Linux es un sistema operativo potente." > documento.txt
echo "Aprenderemos a usar GREP hoy." >> documento.txt
echo "grep busca texto rapido." >> documento.txt
echo "Ubuntu 24.04 es la version actual." >> documento.txt
echo "ERROR: Fallo de conexion en el puerto 80." > logs.log
echo "INFO: Usuario jose ha iniciado sesion." >> logs.log
echo "WARN: Memoria libre baja (90MB)." >> logs.log
echo "ERROR: El disco esta lleno (99%)." >> logs.log

I. Uso Básico y Opciones Fundamentales

El uso más simple de grep es buscar un patrón (una palabra o frase) dentro de un archivo.

OpciónDescripción
BásicoBusca el patrón en el archivo.
-iIgnora mayúsculas y minúsculas (búsqueda insensible a mayúsculas).
-vInvierte la búsqueda: muestra las líneas que NO coinciden con el patrón.
-wFuerza a que la coincidencia sea una palabra completa.
-nMuestra el número de línea donde se encontró la coincidencia.

Ejemplos Prácticos

  1. Búsqueda simple (sensible a mayúsculas):
grep "grep" documento.txt
# Salida: grep busca texto rapido.
  1. Ignorar mayúsculas y minúsculas (-i):
grep -i "linux" documento.txt
# Salida: Linux es un sistema operativo potente.
  1. Mostrar las líneas que NO contienen la palabra "ERROR" (-v):

Útil para filtrar mensajes normales o de información.

grep -v "ERROR" logs.log
# Salida:
# INFO: Usuario jose ha iniciado sesion.
# WARN: Memoria libre baja (90MB).
  1. Buscar la palabra "es" completa (-w) y mostrar número de línea (-n):

Sin -w, también coincidiría con palabras como "estudio" o "ses**ion".

grep -w -n "es" documento.txt
# Salida: 1:Linux es un sistema operativo potente.

II. Opciones de Contexto y Formato

Estas opciones son cruciales para el análisis de logs o archivos grandes, ya que ayudan a entender la coincidencia en su contexto.

OpciónDescripción
-cMuestra solo la cantidad de líneas que contienen la coincidencia.
-lMuestra solo el nombre del archivo donde se encontró la coincidencia.
-A NMuestra N líneas de texto DESPUÉS de la línea que coincide (After).
-B NMuestra N líneas de texto ANTES de la línea que coincide (Before).
-C NMuestra N líneas de contexto ALREDEDOR de la línea que coincide.

Ejemplos Prácticos

  1. Contar cuántos errores hay en los logs (-c):
grep -c "ERROR" logs.log
# Salida: 2
  1. Mostrar la línea del ERROR y las 2 líneas siguientes (-A 2):

Usaremos el primer ERROR para el ejemplo.

grep -A 2 "Fallo de conexion" logs.log
# Salida:
# ERROR: Fallo de conexion en el puerto 80.
# INFO: Usuario jose ha iniciado sesion.
# WARN: Memoria libre baja (90MB).
  1. Mostrar 1 línea de contexto alrededor del aviso (-C 1):
grep -C 1 "WARN" logs.log
# Salida:
# INFO: Usuario jose ha iniciado sesion.
# WARN: Memoria libre baja (90MB).
# ERROR: El disco esta lleno (99%).

III. Búsqueda Recursiva y Múltiples Archivos

grep puede buscar en múltiples archivos a la vez, incluyendo subdirectorios.

OpciónDescripción
-rBusca recursivamente en todos los subdirectorios.
*El comodín busca en todos los archivos del directorio actual.
--excludeOmite archivos o directorios específicos durante la búsqueda.

Ejemplos Prácticos

  1. Buscar "Ubuntu" en todos los archivos del directorio actual (*):
grep "Ubuntu" *
# Salida:
# documento.txt:Ubuntu 24.04 es la version actual.
  1. Búsqueda recursiva de "jose" en todo el directorio actual (-r):

Asumiendo que el directorio de jose tiene subcarpetas con más archivos.

grep -r "jose"
# Salida:
# ./logs.log:INFO: Usuario jose ha iniciado sesion.
  1. Buscar recursivamente pero excluyendo un archivo específico (--exclude):
grep -r --exclude=logs.log "es"
# Salida:
# ./documento.txt:Linux es un sistema operativo potente.
# ./documento.txt:grep busca texto rapido.
# ./documento.txt:Ubuntu 24.04 es la version actual.

IV. Expresiones Regulares (Extended y Fixed)

grep utiliza por defecto expresiones regulares básicas (Basic Regular Expressions - BRE). Para expresiones más potentes (como +, ? o |), se recomienda usar la opción extendida.

OpciónDescripción
-EHabilita las Expresiones Regulares Extendidas (E-grep). Permite usar símbolos como `
-FTrata el patrón como una cadena de texto fijo (Fixed-grep). Desactiva las expresiones regulares, lo que hace la búsqueda más rápida.

Ejemplos Prácticos

  1. Usar OR (|) para buscar múltiples patrones (-E):

Busca líneas que contengan "ERROR" o "WARN".

grep -E "ERROR|WARN" logs.log
# Salida:
# ERROR: Fallo de conexion en el puerto 80.
# WARN: Memoria libre baja (90MB).
# ERROR: El disco esta lleno (99%).
  1. Buscar el inicio de línea usando el ancla ^ (BRE):

Busca todas las líneas que inician con "INFO".

grep "^INFO" logs.log
# Salida: INFO: Usuario jose ha iniciado sesion.
  1. Buscar el final de línea usando el ancla $ (BRE):

Busca la línea que termina con la palabra "potente.".

grep "potente.$" documento.txt
# Salida: Linux es un sistema operativo potente.

Las expresiones regulares (regex) son donde grep muestra su verdadero poder. Las opciones [] y ^ (como inicio de patrón dentro de []) son cruciales para definir conjuntos de caracteres.

Creación de Archivos de Prueba

Primero, crearemos un archivo llamado numeros_letras.txt para practicar con patrones de caracteres:

echo "Texto de prueba A1" > numeros_letras.txt
echo "Texto de prueba B2" >> numeros_letras.txt
echo "Texto de prueba C3" >> numeros_letras.txt
echo "Texto de prueba D4" >> numeros_letras.txt
echo "Linea sin numeros ni mayusculas" >> numeros_letras.txt
echo "Palabra-clave" >> numeros_letras.txt
echo "Palabra_clave" >> numeros_letras.txt
echo "FIN" >> numeros_letras.txt

V. Opciones con Patrones de Caracteres ([ ] y ^ dentro de [])

1. Corchetes [ ] (Coincidencia con Conjunto de Caracteres)

Los corchetes permiten especificar un conjunto de caracteres de los cuales solo uno debe coincidir en la posición indicada.

SintaxisDescripción
[abc]Coincide si el carácter en esa posición es a, b o c.
[0-9]Coincide con cualquier dígito del 0 al 9.
[A-Za-z]Coincide con cualquier letra (mayúscula o minúscula).

Ejemplos Prácticos

  1. Buscar líneas que contienen "B" o "D" al inicio de una palabra:
grep "B[2]\|D[4]" numeros_letras.txt
# Salida (usando grep -E para el OR |):
# Texto de prueba B2
# Texto de prueba D4

# Una forma más sencilla (coincidencia con B o D, seguido de 2 o 4):

grep " [BD][24]" numeros_letras.txt
# Salida:
# Texto de prueba B2
# Texto de prueba D4
  1. Buscar líneas que terminan con un dígito ([0-9]):
grep "[0-9]$" numeros_letras.txt
# Salida:
# Texto de prueba A1
# Texto de prueba B2
# Texto de prueba C3
# Texto de prueba D4
  1. Buscar líneas que contienen una vocal minúscula ([aeiou]):
grep "[aeiou]" numeros_letras.txt
# Salida (Todas las líneas tienen vocales, excepto quizás "FIN"):
# Texto de prueba A1
# Texto de prueba B2
# Texto de prueba C3
# Texto de prueba D4
# Linea sin numeros ni mayusculas
# Palabra-clave
# Palabra_clave

2. Símbolo de Negación [^] (No Coincidencia con Conjunto de Caracteres)

Cuando el símbolo de intercalación ^ se coloca inmediatamente después del corchete de apertura ([), invierte el significado, buscando cualquier carácter excepto los listados dentro del conjunto.

SintaxisDescripción
[^abc]Coincide con cualquier carácter que NO sea a, b o c.
[^0-9]Coincide con cualquier carácter que NO sea un dígito.

Ejemplos Prácticos

  1. Buscar líneas que NO contienen mayúsculas ([^A-Z]):

Este patrón debe ir acompañado de otros, o solo buscará cualquier carácter que no sea una mayúscula. Usaremos -v como alternativa más limpia para este caso, o buscaremos una línea donde el primer carácter sea una letra minúscula:

Opción A: Buscar líneas que contienen al menos un carácter que NO sea un número:

grep "[^0-9]" numeros_letras.txt
# Salida: (Todas las líneas coinciden porque todas tienen letras, espacios, etc.)
# ... todas las líneas ...

Opción B: Buscar líneas donde el último carácter NO es un dígito:

grep "[^0-9]$" numeros_letras.txt
# Salida:
# Linea sin numeros ni mayusculas
# Palabra-clave
# Palabra_clave
# FIN
  1. Buscar líneas que contienen caracteres especiales o puntuación, excluyendo letras y números:

Busca un carácter que NO sea una letra (A-Za-z), un número (0-9) o un espacio ( ):

grep "[^A-Za-z0-9 ]" numeros_letras.txt
# Salida:
# Palabra-clave
# Palabra_clave
  1. Buscar la palabra "clave" si le precede una puntuación o símbolo:

Busca la palabra "clave" precedida de un guion o un guion bajo, excluyendo el espacio.

grep "[^ ]clave" numeros_letras.txt
# Salida:
# Palabra-clave
# Palabra_clave
