Los comandos Bash son conjunto de parámetros utilizados para la administración y configuración del sistema, así como un conjunto de combinaciones especiales de teclas para realizar tareas específicas en entornos Linux/Unix mediante un intérprete de comandos Bash.

Hay cientos de comandos, algunos muy poderosos y útiles pero también podemos encontrar algunos que podríamos considerar “poco útiles” o “inútiles” pero que tiene su gracia.

Veamos algunos de ellos:

1.- Una terminal que habla:

El comandoespeak sirve para que tu equipo recite lo que le indiques.

Primero hay que instalar el paquete con:

sudo apt install espeak

Y su síntesis sería:

espeak -v spanish "Texto a reproducir" espeak -v spanish "Un fantasma en el sistema"

2.- Una vaca en la terminal

Muestra una vaca en la terminal utilizando los símbolos ascii diciendo la frase que quieras mostrar.

instalamos el paquete con:

sudo apt install cowsay

Síntesis:

cowsay Texto_a_mostrar

3.- Un pony en la terminal

Lo mismo que Cowsay pero en esta ocasión muestra lo que debería ser un pony o “algo parecido”, aunque más bien parece un jugador de fútbol diciendo la frase que quieras mostrar.

instalamos el paquete con:

sudo snap install ponysay

Síntesis:

ponysay Texto_a_mostrar

4.- Una vaca pensando.

Es igual que cowsay pero en este caso muestra la salida a modo de pensamiento:

Síntesis:

ponysay Texto_a_mostrar

No se ha encontrado la orden «sl», pero se puede instalar con:

sudo apt install sl

6.- Repetir una cadena

El comando yes sólo sirve para repetir una cadena hasta que termines su proceso presionando Crtl+C. Aunque puede parecer inútil resulta muy interesante si queremos automatizar un script indicándole la ruta donde se encuentra.

Síntesis:

yes Un fantasma en el sistema

7.- Invertir la entrada

El comando rev tiene por “utilidad” revertir la entrada que le pongamos, es decir que si ponemos un a palabra la mostrará literalmente al revés. Se ejecutará hasta que lo detengamos con Crtl+C Síntesis:

rev
entrada_a_invertir

8.- Un banner en la terminal.

Con el comando banner puedes mostrar un texto a modo de banner en tu terminal.

instalamos el paquete con:

sudo apt install sysvbanner

Síntesis:

banner texto_a_mostrar

9.- Frases aleatorias.

El comando fortune es el equivalente a las conocidas galletas de la fortuna; te muestra una frase o un texto de algún conocido autor y lo cita. instalamos el paquete con:

sudo apt install fortune-mod

Síntesis:

fortune

10.- Textos coloridos.

Un comando muy similar a banner es toilet pero en este caso, la salida, es a color.

Puedes ver las distintas opciones que te ofrece con:

man toilet

instalamos el paquete con:

sudo apt install toilet

Síntesis:

toilet -f mono12 -F metal Un Fantasma en el sistema

11.- Un cronómetro.

La suma de los comandos time y cat se puede utilizar a modo de cronómetro.

Se ejecuta en segundo plano hasta que lo detengas con Crtl+C y luego te informa del tiempo transcurrido entre el inicio y el final de su proceso:

Síntesis:

time cat

12.- Calendario.

Puedes ver un calendario en la terminal con el comando cal. Para ver las distintas opciones que te ofrece utiliza su ayuda:

man cal

Síntesis:

cal

13.- Fuego en la terminal.

El comando aafire muestra un efecto de fuego en tu terminal hasta que lo detengamos con Crtl+C.

instalamos el paquete con:

sudo apt install libaa-bin

Síntesis:

aafire

14.- Escribe en ASCII

Si te gusta el arte ASCII, este es tu comando. El comando figlet transforma en ASCII cualquier cadena que le marques.

Síntesis:

figlet

Texto_a_mostrar

15.- Un gato en la terminal

Con el comando oneko puedes poner un gato que perseguirá al cursor por toda la pantalla hasta que lo detengas con Crtl+C.

instalamos el paquete con:

sudo apt install oneko

Síntesis:

oneko

Puedes incluso elegir tu mascota con las opciones que te ofrece:

oneko -tora (muestra un tigre)

oneko -dog (muestra un perro)

oneko -sakura (muestra a Sakura Kinomoto)

oneko -tomoyo (muestra a Tomoyo Daidouji)

Puedes desinstalarlo con:

sudo apt remove oneko

16.- Matrix

El comando cmatrix muestra en pantalla el conocido efecto Matrix hasta que lo detengas con Crtl+C instalamos el paquete con:

sudo apt install cmatrix

Síntesis:

cmatrix

17.- Descomposición en factores primos.

Con el comando factor puedes dividir un número dado en factores primos.

Síntesis:

factor número_a_descomponer

18.- El comando más corto.

De entre todos los comandos, probablemente el más corto sea w.

Este comando nos muestra información sobre los usuarios actuales, como su nombre, tiempo de inicio de sesión… Síntesis:

w
