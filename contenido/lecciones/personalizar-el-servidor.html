Personalizar tu entrada al sistema

En Linux podemos personalizar los siguientes mensajes:

  • Mensaje de inicio de Sesión al realizar un Login exitoso en el sistema (ya sea desde una terminal ó accediendo via SSH.
  • Mensaje previo al Login (cuando accedemos por terminal directa al equipo)

1. Mensaje Previo al Login

Este mensaje se presenta al solicitar los datos de autenticación cuando intentamos acceder directamente desde una terminal al sistema.

Para incluir un mensaje o banner personalizado editamos el archivo:

sudo nano /etc/issue

El archivo /etc/issue puede contener ciertos códigos de escape para mostrar el nombre del sistema, la fecha y la hora, etc. Todos los códigos de escape consisten en una barra diagonal inversa (\) seguida inmediatamente de una de las letras que se explican a continuación.

\b Muestra la velocidad en baudios de la línea actual

\d Muestra la fecha actual.

\s Muestra el nombre del sistema, el nombre del sistema operativo.

\l Muestra el nombre de la línea tty actual.

\m Muestra el identificador de arquitectura de la máquina, por ejemplo, i486

\n Muestra el nombre de nodo del equipo, también conocido como nombre de host.

\o Muestra el nombre de dominio del equipo.

\r Muestra el número de versión del sistema operativo, por ejemplo. 1.1.9.

\t Muestra la hora actual.

\u Muestra el número de usuarios actuales que han iniciado sesión.

\U Muestra la cadena "1 usuario" o "usuarios" donde es el número de usuarios actuales que han iniciado sesión.

\v Muestra la versión del sistema operativo, por ejemplo, la fecha de compilación, etc.

\4 Visualiza la dirección IP de la máquina

\4{eth0} Solo visualiza la dirección IP de la tarjeta eth0 si hay varias en el sistema.

Puedes ver las diferentes opciones y parámetros admitidos en tu sistema puedes hacerlo con:

man getty

2. Archivo /etc/issue.net (Acceso Remoto SSH)

El archivo cumple una función similar a /etc/issue, pero se muestra cuando un usuario intenta conectarse al servidor de forma remota a través de SSH (Secure Shell) o Telnet.

  • Cuándo se muestra: Antes de la solicitud de nombre de usuario del servicio (como sshd).
  • Códigos de Escape: Soporta los mismos códigos de escape de que usamos antes (como , $\text{\r}$, $\text{\m}$, $\text{\4}$).
  • Uso Recomendado: Se utiliza a menudo para mostrar advertencias de seguridad o el logo del sistema.

Ejemplo de implementación:

# Contenido de /etc/issue.net
sudo nano /etc/issue.net

FEVAL SERVER
------------------------------------
ACCESO RESTRINGIDO - SERVIDOR PRIVADO
USER: feval
PASS: dingdong
=================================================
\S
Kernel \r en \m
IP: \4
Hostname: \n
Tiempo de actividad: \t
Fecha: \d
Hora: \t
Usuarios Logueados: \u

2. Archivo /etc/motd (Message of the Day)

El archivo es probablemente el más útil para la personalización y la información del sistema. Es lo que se muestra al usuario después de que inicia sesión correctamente (tanto en la consola como por SSH).

A diferencia de los archivos que son estáticos, utiliza de forma dinámica a través de la carpeta /etc/update-motd.d/.

Personalización Estática

Puedes añadir contenido directamente al archivo base /etc/motd. Este contenido se mostrará antes o después de cualquier script dinámico.

Personalización Dinámica (Recomendada)

La mejor manera es crear scripts ejecutables en la carpeta /etc/update-motd.d/. Estos scripts generan contenido dinámico (uso de CPU, actualizaciones pendientes, etc.) cada vez que alguien inicia sesión.

Pasos para un script personalizado:

  1. Crea un nuevo script en la carpeta:
sudo nano /etc/update-motd.d/90-custom-message
  1. Añade tu mensaje y usa comandos para obtener información en tiempo real:
#!/bin/bash
echo "============================================================"
echo "¡BIENVENIDO AL SERVIDOR DE FEVAL, ${USER}!"
echo "El uso actual del disco en / es: $(df -h / | awk 'NR==2 {print $5}')"
echo "Último inicio de sesión: $(last -1 | grep -v 'wtmp' | awk '{print $4, $5, $6}')"
echo "============================================================"
  1. Dale permisos de ejecución al script:
sudo chmod +x /etc/update-motd.d/90-custom-message

Resultado: Cada vez que el usuario inicie sesión, verá tu mensaje personalizado con información en tiempo real, lo que le da un toque mucho más dinámico que el archivo /etc/issue.

La forma más fácil de generar texto en arte ASCII es usando un programa llamado figlet y, opcionalmente, lolcat para darle color.

Pasos:

  1. Instalar herramientas:
sudo apt install figlet lolcat
  1. Probar figlet: Escribe un texto y canalízalo a figlet.
echo "FEVAL SERVER" | figlet

o en dos líneas:

echo -e "FEVAL\nSERVER" | figlet
  1. Probar lolcat (con color):
printf "FEVAL\nSERVER\n" | figlet -f slant | lolcat

figlet -f slant usa una fuente diferente. Puedes ver más fuentes en /usr/share/figlet/.

Puedes añadir la salida del comando printf "FEVAL\nSERVER\n" | figlet -f slant | lolcat al inicio del fichero /etc/issue

1. Generar la Salida de figlet y Guardarla en un Archivo Temporal

La clave es guardar la salida del comando en un archivo nuevo y temporal. Dado que /etc/issue no soporta códigos de color (solo se ve al conectarse por SSH), solo necesitas la salida de figlet.

# 1. Ejecuta el comando y guarda la salida en un archivo temporal.

# Usamos 'printf' y 'figlet' (sin 'lolcat', ya que /etc/issue no soporta color).
printf "FEVAL\nSERVER\n" | figlet -f slant > /tmp/temp_header.txt

2. Concatenar y Reemplazar el Archivo Original

Ahora, concatenamos el contenido nuevo (/tmp/temp_header.txt) y el contenido antiguo (/etc/issue) en un nuevo archivo, y luego reemplazas el original.

# 2. Concatena el archivo temporal (nuevo) y el archivo original (/etc/issue)

# y redirige la salida al archivo temporal para la fusión.

cat /tmp/temp_header.txt /etc/issue > /tmp/temp_issue_merged.txt
# 3. Mueve (renombra) el archivo fusionado de vuelta a la ubicación original.
# Esto requiere permisos de root (sudo).
sudo mv /tmp/temp_issue_merged.txt /etc/issue

3. Limpiar el Archivo Temporal

# 4. Elimina el archivo temporal.
rm /tmp/temp_header.txt

Recomendación para mantenerlo actualizado

Para que el archivo muestre datos actualizados (como IP o interfaz), puedes usar un script en /etc/rc.local o un servicio systemd que lo regenere en cada arranque:

#!/bin/bash
echo "======================================" > /etc/issue
echo " SERVER - ACCESO RESTRINGIDO" >> /etc/issue
echo " IP: $(hostname -I | awk '{print $1}')" >> /etc/issue
echo " Interfaz de red: $(hostname)" >> /etc/issue
echo "======================================" >> /etc/issue
uname -a >> /etc/issue

Configurar el Firewall (UFW)

Si el firewall de Ubuntu (UFW) está activo, bloqueará el puerto 23 por defecto. Debes abrirlo explícitamente para permitir la conexión.

sudo ufw allow 23/tcp
sudo ufw status
