Comando mount (Montar)

El comando mount hace que un dispositivo de almacenamiento (como una partición de disco, un USB o un sistema de archivos de red) sea accesible en el árbol de directorios de Linux.

Opción ComúnDescripción
-aMonta todos los sistemas de archivos listados en /etc/fstab.
-t TIPOEspecifica el tipo de sistema de archivos (ej: ext4, vfat, ntfs).
-o OPCIONESEspecifica opciones de montaje (ej: ro para solo lectura, rw para lectura/escritura).

Ejemplos Prácticos con mount

Usa el comando lsblk para listar todos los dispositivos de bloque (discos, particiones, USB) y ver cómo están nombrados:

lsblk

Solo necesitas crear el directorio que el comando mount espera antes de intentar montarlo:

sudo mkdir /mnt/usbdata
TareaComando Ejecutado por jose (con sudo)Explicación
Montar un USB (ej: /dev/sdb1)sudo mount /dev/sdb1 /mnt/usbdataMonta la partición /dev/sdb1 en el punto de montaje /mnt/usbdata, haciéndola accesible.
Montar con opción de solo lecturasudo mount -o ro /dev/cdrom /media/cdMonta un CD-ROM en modo de solo lectura (ro).
Mostrar sistemas de archivos montadoscat /proc/mountsMuestra una lista de todos los sistemas de archivos actualmente montados.

Comando umount (Desmontar) eject

El comando umount separa un dispositivo montado del árbol de directorios de Linux, permitiendo que el dispositivo sea retirado de forma segura.

Opción ComúnDescripción
-lDesmontaje perezoso (lazy): Desmonta inmediatamente del árbol, pero espera a que el sistema de archivos esté realmente libre.

Ejemplos Prácticos con umount

TareaComando Ejecutado por jose (con sudo)Explicación
Desmontar por dispositivosudo umount /dev/sdb1Desmonta el dispositivo /dev/sdb1.
Desmontar por punto de montajesudo umount /mnt/usbdataDesmonta el sistema de archivos montado en el punto /mnt/usbdata.
Desmontaje forzado (si falla)sudo umount -l /mnt/usbdataIntenta un desmontaje "perezoso" si el proceso normal falla porque está en uso.

Comando fdisk (Partition Manipulator)

fdisk es una utilidad de manipulación de tablas de particiones para discos que usan la tabla de particiones MBR (Master Boot Record). Es una herramienta interactiva, ideal para crear o modificar particiones en discos que no son la partición del sistema operativo.

Comando Interno (fdisk)Descripción
pImprimir la tabla de particiones actual. (Muestra las particiones existentes en el disco seleccionado.)
nCrear una nueva partición. (Pide el tipo de partición, el número y los sectores de inicio/fin.)
dEliminar una partición. (Pide el número de partición a eliminar.)
wEscribir los cambios al disco (guardar). (Aplica las modificaciones de la tabla de particiones al disco físico.)
qSalir sin guardar los cambios. (Sale del programa sin aplicar las modificaciones de la tabla de particiones.)

Comandos Adicionales Útiles de fdisk

Comando Interno (fdisk)Descripción Adicional
mImprimir este menú de ayuda (muestra todos los comandos internos disponibles).
tCambiar el tipo de sistema de archivos (ID) de una partición (ej., cambiar de Linux a FAT32).
lListar los tipos de partición conocidos (los códigos que se usan con el comando t).

Paso Seguro: Usar fdisk en el Disco Existente (/dev/sda)

La forma más sencilla y segura de practicar los comandos de fdisk (como p, n, d, w, q) sin riesgo de dañar tu sistema operativo es iniciar el programa con tu disco principal (/dev/sda), pero asegurarte de salir con el comando q (quit).

El comando q saldrá sin guardar ningún cambio, lo que te permite simular la edición sin modificar realmente tu disco duro.

sudo fdisk /dev/sda

nCrear una nueva partición. Puedes practicar la simulación de creación aquí.Seguro (los cambios son temporales).

Ejemplo de Creación de Partición con fdisk

Este ejemplo asume que tienes espacio libre al final del disco (que es lo más común cuando se practica en un disco virtual).

1. Iniciar fdisk

Inicia el programa con el disco que quieres editar (en tu caso, /dev/sda):

sudo fdisk /dev/sda

Verás el prompt de comandos:

Welcome to fdisk (util-linux 2.37.2).

Changes will remain in memory only, until you decide to write them.

Be careful before using the write command.

Command (m for help):

2. Imprimir la Tabla (Opcional, pero Recomendado)

Usa p para ver el estado actual del disco y el espacio libre:

Command (m for help): p

3. Iniciar la Creación

Usa el comando n para crear una nueva partición:

Command (m for help): n

El programa te hará una serie de preguntas:

Pregunta de fdiskRespuesta de EjemploExplicación
Select the type of partition:p (primary) o e (extended)Si eliges p, te preguntará el número de partición (ej. 3 o 4).
Partition number (3-4, default 3):3 (Enter)Seleccionamos el siguiente número de partición disponible.
First sector (1048576-104857599, default 1048576):(Enter)Aceptamos el valor por defecto, que es el inicio del espacio libre disponible.
Last sector, +/-sectors or +/-size{K,M,G} (1048576-104857599, default 104857599):+5GEspecificamos el tamaño, por ejemplo, 5 Gigabytes. También podrías introducir el número del último sector disponible.

Una vez que completes la última pregunta, fdisk te notificará que la partición ha sido creada (ej. Created a new partition 3 of type 'Linux' and of size 5 GiB).

4. Verificar la Partición Creada Temporalmente

Vuelve a usar p para ver la tabla y confirmar que la nueva partición (/dev/sda3) está en la lista (recuerda: solo está en memoria):

Command (m for help): p

Nota:

No nos ha pedido elegir entre p (primaria) o e (extendida) porque estamos utilizando un disco que tiene una tabla de particiones GPT (Tipo de etiqueta de disco: gpt).

Explicación de la Diferencia

En MBR, solo podías tener 4 particiones primarias, por lo que necesitabas la opción "extendida" para crear más de cuatro.

En cambio, nuestro disco está usando el esquema de particiones GPT (GUID Partition Table), que es el estándar moderno.

  1. GPT no tiene particiones primarias/extendidas: En GPT, todas las particiones son simplemente "particiones" y el límite no es de 4, sino de 128 particiones (o más, dependiendo del sistema).
  2. fdisk lo sabe: Cuando fdisk detecta una etiqueta GPT (como indica la línea Tipo de etiqueta de disco: gpt), omite la pregunta sobre el tipo (p o e) y asume que vas a crear una partición estándar de Linux.
  3. Resultado: Por eso, te pasa directamente a la pregunta del número de partición (Número de partición (3-128, valor predeterminado 3):) y luego asume el tipo 'Linux filesystem' por defecto.

Análisis de la Creación (Partición 3)

Hemos creado la partición 3, pero ha salido muy pequeña porque el espacio libre disponible en ese disco era mínimo:

ParámetroValor que usamos
Inicio del disco:2048
Final del disco:107583040
Particiones existentes:sda1 (1M) y sda2 (51.3G)
Espacio libre disponible:Del sector 107579392 al 107583006.
Tamaño del espacio libre:Solo 3615 sectores, lo que equivale a 1 MiB (el tamaño de la partición 3 que creaste).
Conclusión

La partición 3 se creó de 1 MiB porque solo nos quedaba ese espacio libre en el disco de 51.3 GiB después de que se usara el espacio para sda1 y sda2. La creación fue exitosa dentro de las restricciones de espacio de nuestro disco.

3. Salir de Forma Segura

Cuando termines de practicar, escribe q y presiona Enter para salir sin modificar nada.

Command (m for help): q

Si por accidente escribieras w (write/guardar), podrías dañar tu sistema operativo. Asegúrate siempre de usar q para salir cuando solo estés practicando.

Si Quieres Particionar un Disco Real

Si en el futuro quieres practicar la partición en un disco real sin riesgo, el método correcto es:

  1. Apagar la VM.
  2. En la configuración de VirtualBox, ir a Almacenamiento.
  3. Añadir un nuevo disco virtual (VDI) de un tamaño pequeño (ej: 1 GB). Este aparecerá como /dev/sdb.
  4. Arrancar la VM y ejecutar sudo fdisk /dev/sdb.
  5. Entonces sí, podrías usar w (write/guardar) sin riesgo para tu sistema operativo principal.

Comando parted (Partition Manipulator)

parted es una utilidad de manipulación de tablas de particiones, a menudo preferida sobre fdisk porque soporta tablas de particiones GPT (GUID Partition Table) y discos de más de 2 TB. Puede usarse de forma interactiva o no interactiva.

Ejemplos Prácticos con parted

TareaComando Ejecutado por jose (con sudo)Explicación
Mostrar la tabla de particionessudo parted -lMuestra las tablas de particiones de todos los discos de forma no interactiva (como fdisk -l).
Ver detalles de un discosudo parted /dev/sda printMuestra la información de las particiones del disco /dev/sda y su tabla de particiones (MBR/GPT).
Crear una nueva partición (no interactivo)sudo parted /dev/sdb mkpart primary ext4 0% 1000MBCrea una partición primaria, de tipo ext4, desde el inicio hasta 1 GB en el disco /dev/sdb.

1. Comando mount — Montar sistemas de archivos

mount se utiliza para montar un dispositivo o partición en un punto del sistema de archivos, haciéndolo accesible.

Sintaxis

sudo mount [opciones] dispositivo punto_de_montaje

Ejemplos prácticos

1.1. Ver los sistemas de archivos montados

mount

Muestra todas las particiones y dispositivos actualmente montados.

1.2. Montar una unidad USB

Supón que el dispositivo es /dev/sdb1 y deseas montarlo en /mnt/usb:

sudo mkdir -p /mnt/usb
sudo mount /dev/sdb1 /mnt/usb

1.3. Montar con un tipo de sistema de archivos específico

sudo mount -t vfat /dev/sdb1 /mnt/usb

Monta una memoria USB con formato FAT32.

1.4. Montar en modo solo lectura

sudo mount -o ro /dev/sdb1 /mnt/usb

1.5. Montar automáticamente con /etc/fstab

Añadir una línea como:

UUID=XXXX-XXXX /mnt/usb vfat defaults 0 0

2. Comando umount — Desmontar sistemas de archivos

umount (sin “n”) se usa para desmontar un dispositivo o punto de montaje.

Sintaxis

sudo umount [dispositivo | punto_de_montaje]

Ejemplos prácticos

2.1. Desmontar una memoria USB

sudo umount /mnt/usb

2.2. Desmontar usando el nombre del dispositivo

sudo umount /dev/sdb1

2.3. Desmontar cuando está ocupado

Si aparece el error “device is busy”, puedes ver qué procesos lo usan:

sudo lsof /mnt/usb

y luego cerrarlos o forzar el desmontaje:

sudo umount -l /mnt/usb

7. Comando fdisk — Administrar particiones MBR

fdisk es una herramienta interactiva para crear, eliminar o modificar particiones en discos con esquema MBR.

Solo debe usarse con precaución y privilegios de sudo.

Sintaxis

sudo fdisk [dispositivo]

Ejemplos prácticos

7.1. Listar particiones de todos los discos

sudo fdisk -l

7.2. Administrar un disco específico

sudo fdisk /dev/sdb

Dentro de fdisk:

  • m → mostrar ayuda
  • p → listar particiones
  • n → crear nueva partición
  • d → eliminar partición
  • w → guardar cambios y salir
  • q → salir sin guardar

7.3. Ver información del disco principal

sudo fdisk -l /dev/sda

8. Comando parted — Administrar particiones (MBR y GPT)

parted es una herramienta más moderna que fdisk, compatible con discos GPT y más grandes.

Sintaxis

sudo parted [dispositivo] [comando]

Ejemplos prácticos

8.1. Ver información de particiones

sudo parted -l

8.2. Entrar en modo interactivo

sudo parted /dev/sdb

Dentro de parted:

  • print → mostrar particiones
  • mklabel gpt → crear tabla GPT
  • mkpart primary ext4 1MiB 10GiB → crear partición
  • rm 1 → eliminar partición 1
  • quit → salir

8.3. Crear una partición de 5 GB automáticamente

sudo parted /dev/sdb mkpart primary ext4 1MiB 5GiB

8.4. Ver espacio libre en el disco

sudo parted /dev/sda print free
