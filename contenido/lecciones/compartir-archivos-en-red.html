1) Conceptos clave

  • NFS (Network File System) → clásico en entornos Linux/Unix, rápido y sencillo.
  • Samba (SMB/CIFS) → protocolo de Windows, permite compartir carpetas entre Linux ↔︎ Windows.
  • scp / sftp → transferencia segura puntual por SSH, no es “compartir permanente”.

NFS (Linux a Linux) y Samba (Linux ↔︎ Windows).

2) Compartir archivos con NFS

Instalación (Debian/Ubuntu)

sudo apt update
sudo apt install -y nfs-kernel-server

Configurar carpeta compartida

  1. Crear carpeta y asignar permisos:
sudo mkdir -p /srv/nfs/compartido
sudo chown nobody:nogroup /srv/nfs/compartido
sudo chmod 777 /srv/nfs/compartido
  1. Editar /etc/exports y añadir:
sudo nano /etc/exports

/srv/nfs/compartido 192.168.1.0/24(rw,sync,no_subtree_check)

Esto comparte la carpeta con toda la subred 192.168.1.0/24.

  1. Aplicar cambios:
sudo exportfs -ra
sudo systemctl restart nfs-kernel-server

Cliente NFS

Usamos la ip de la máquina Ubuntu:

sudo apt install -y nfs-common
sudo mount 192.168.1.41:/srv/nfs/compartido /mnt

Ya tienes tu servidor NFS funcionando en 192.168.1.41. Ahora toca ver cómo acceder desde otros equipos de tu red local (por ejemplo, otra VM o un portátil conectado al mismo router).

Pasos en el cliente NFS (otro equipo)

  1. Instalar utilidades NFS (en Ubuntu/Debian):
sudo apt update
sudo apt install -y nfs-common
  1. Crear un punto de montaje (carpeta donde se verá el recurso compartido):
sudo mkdir -p /mnt/nfs
  1. Montar el recurso compartido desde el servidor:
sudo mount 192.168.1.41:/srv/nfs/compartido /mnt/nfs
  1. Verificar:
df -h | grep nfs
ls -la /mnt/nfs

Montaje automático al arrancar

Si quieres que el cliente monte el recurso siempre al iniciar, edita /etc/fstab en el cliente y añade:

192.168.1.41:/srv/nfs/compartido /mnt/nfs nfs defaults 0 0

Luego prueba con:

sudo mount -a

Cosas a tener en cuenta

  • En el servidor, en /etc/exports, asegúrate de haber permitido a la red local:
/srv/nfs/compartido 192.168.1.0/24(rw,sync,no_subtree_check)
  • Si usas VirtualBox, revisa que las VMs estén en modo puente (bridged) o red interna para que se vean entre sí.
  • Puedes probar conectividad con:
ping 192.168.1.41

Ejercicio 1

  • En VM1 (servidor): exporta /srv/nfs/compartido.
  • En VM2 (cliente): móntalo en /mnt.
  • Crea un archivo en el cliente y comprueba que aparece en el servidor.

3) Compartir archivos con Samba

Instalación

sudo apt install -y samba

Configurar carpeta compartida

  1. Crear carpeta:
sudo mkdir -p /srv/samba/publico
sudo chmod 777 /srv/samba/publico
  1. Editar /etc/samba/smb.conf y añadir al final:
sudo nano /etc/samba/smb.conf

[Publico]
path = /srv/samba/publico
browsable = yes
writable = yes
guest ok = yes
read only = no
  1. Reiniciar servicio:
sudo systemctl restart smbd

Acceso desde cliente Linux

smbclient -L //192.168.1.41 -N
smbclient //192.168.1.41/Publico -N

Acceso desde Windows

  • En el explorador: \\192.168.1.41\Publico
  • Copiar/pegar archivos.

Ejercicio 2

  1. Configura Samba para compartir /srv/samba/publico.
  2. Accede desde otra VM Linux con smbclient o desde Windows con \\IP.
  3. Copia un archivo y verifica que aparece en el servidor.

4) Compartir archivos de forma puntual (scp, sftp)

Copiar con scp

scp archivo.txt usuario@192.168.56.20:/home/usuario/

Acceder con sftp

sftp usuario@192.168.56.20

Ejercicio 3

  1. Desde un cliente, copia un archivo a otro host con scp.
  2. Comprueba que se transfirió correctamente.

5) Ejercicio integrador

Escenario:

  • VM1 (Servidor Linux): comparte /srv/nfs/compartido vía NFS y /srv/samba/publico vía Samba.
  • VM2 (Cliente Linux): monta el NFS en /mnt/nfs.
  • VM3 (Cliente Windows o Linux): accede al recurso Samba.

Objetivo:

  • Crear un archivo compartido y verlo desde las otras máquinas.

6) Cheatsheet rápido

# NFS
sudo apt install nfs-kernel-server nfs-common
sudo nano /etc/exports

sudo exportfs -ra
sudo mount server:/ruta /mnt
# Samba
sudo apt install samba smbclient
sudo nano /etc/samba/smb.conf

sudo systemctl restart smbd
smbclient -L //server -N
# SCP / SFTP
scp file.txt user@host:/path
sftp user@host

Consejos:

  • NFS es más natural en Linux, mientras que Samba es la mejor opción si hay Windows en la red.
  • Para ejercicios rápidos, usa scp/sftp porque no requieren configurar servicios.
