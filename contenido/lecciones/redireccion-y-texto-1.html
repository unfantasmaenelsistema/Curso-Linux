1. Comando cat (Concatenate)

El comando cat (de concatenate, concatenar) es la forma más simple y común de mostrar el contenido completo de uno o más archivos en la salida estándar (la pantalla).

Opción ComúnDescripción
-nNumera todas las líneas de salida.
>Redirige la salida a un nuevo archivo (crea o sobrescribe).
>>Añade la salida al final de un archivo existente.

Ejemplos Prácticos con cat

TareaComando Ejecutado por jose en Ubuntu 24.04Explicación
Ver todo el contenidocat informe.logMuestra el contenido completo de informe.log de golpe.
Ver contenido con numeracióncat -n informe.logMuestra el archivo informe.log, anteponiendo el número de línea a cada una.
Crear un nuevo archivocat > nuevo_archivo.txt (y luego escribir y pulsar Ctrl+D)cat espera la entrada del teclado, y al pulsar Ctrl+D guarda lo escrito en nuevo_archivo.txt.
Concatenar y añadircat informe.log >> informe_completo.logAgrega el contenido de informe.log al final de informe_completo.log (o lo crea si no existe).

2. Comando less

less es un paginador de archivos muy avanzado. Es la mejor opción para ver archivos grandes, ya que carga el archivo por partes, permitiendo navegar hacia adelante y hacia atrás, y buscar texto de forma eficiente.

Comandos de Navegación Clave en less

ComandoAcción
(Arriba/Abajo)Desplazamiento línea a línea.
Espacio o fAvanza una pantalla (página) completa.
b o Ctrl + BRetrocede una pantalla (página) completa.
gIr al inicio del archivo.
GIr al final del archivo.
/patrónBuscar hacia adelante el texto "patrón". Pulsa para la siguiente coincidencia.
?patrónBuscar hacia atrás el texto "patrón".
qSalir de less.

Ejemplo Práctico con less

TareaComando Ejecutado por joseResultado y Uso
Visualizar un archivo grandeless informe.logAbre el archivo en el visor. Dentro de less, presiona / y escribe /ERROR para buscar el error, luego n para repetir la búsqueda, y finalmente q para salir.

3. Comando more

more es un paginador más antiguo y simple que less. Muestra el contenido del archivo pantalla por pantalla, pero no permite navegar hacia atrás de forma sencilla (una vez que pasas una pantalla, no puedes volver). Es menos flexible que less.

Comandos de Navegación Clave en more

ComandoAcción
espacioAvanza a la siguiente pantalla (página).
enterAvanza una línea.
qSalir de more.

Ejemplo Práctico con more

TareaComando Ejecutado por joseResultado y Uso
Visualizar el archivo (limitado)more informe.logMuestra la primera pantalla del archivo. Presiona la barra espaciadora para ver la siguiente pantalla, y q para salir.

4. Comando head

El comando head muestra, por defecto, las primeras 10 líneas de un archivo de texto. Es muy útil para hacer una inspección rápida del comienzo de un archivo, como un log o un archivo de configuración.

Opción ComúnDescripción
-n KMuestra las K primeras líneas del archivo.
-c KMuestra los K primeros bytes del archivo.

Ejemplos Prácticos con head

TareaComando Ejecutado por joseExplicación
Ver las 10 primeras líneashead informe.logMuestra las líneas 1 a 10 del archivo.
Ver las 5 primeras líneashead -n 5 informe.logMuestra solo las líneas 1 a 5, para revisar el inicio de un log.
Ver los primeros 50 byteshead -c 50 informe.logMuestra los primeros 50 caracteres/bytes del archivo.

5. Comando tail

El comando tail muestra, por defecto, las últimas 10 líneas de un archivo. Es crucial para ver la actividad más reciente en archivos de log.

Opción ComúnDescripción
-n KMuestra las K últimas líneas del archivo.
-fModo de seguimiento (follow): Muestra las últimas líneas y se queda esperando a que se añadan nuevas líneas al archivo (ideal para logs en tiempo real).
-FSimilar a -f, pero también reabre el archivo si ha sido renombrado o rotado (más robusto para logs).

Ejemplos Prácticos con tail

TareaComando Ejecutado por joseExplicación
Ver las 10 últimas líneastail informe.logMuestra las líneas 6 a 15 del archivo (las 10 últimas).
Ver las 3 últimas líneastail -n 3 informe.logMuestra solo las líneas 13, 14 y 15 (las tres últimas).
Monitoreo en tiempo real (Crucial)tail -f informe.logMuestra las últimas líneas del log y se queda abierto, actualizando la pantalla cuando se escribe nueva información en el archivo. Usa Ctrl+C para detener el monitoreo.
Combinar con head (Ver un rango)cat informe.log | head -n 10 | tail -n 3Primero muestra todo el archivo (cat), luego toma las primeras 10 líneas (head), y de esas 10, muestra las últimas 3 (es decir, las líneas 8, 9 y 10 del archivo original).
echo "Nueva entrada de log a las 10:45:00" >> /home/jose/informe.log

Ejercicios:

Guía práctica: Visualización y lectura de archivos en Linux

Usuario: jose

Sistema operativo: Ubuntu 24.04

Ruta base de trabajo: /home/jose/documentos/

1. Comando cat — Concatenar y mostrar el contenido de archivos

El comando cat (de concatenate) se utiliza para mostrar el contenido de archivos de texto, unir varios archivos, o incluso crear nuevos.

cat << EOF > /home/jose/notas.txt

==================================================

DOCUMENTO DE PRUEBA Y NAVEGACIÓN

==================================================

Sección A: Introducción

--------------------------------------------------

Esta es la primera sección del archivo de notas. Es una línea corta.

El término CLAVE-1 se repite aquí.

La búsqueda de texto debe comenzar por el inicio de esta sección.

Hay un total de 20 líneas vacías después de esta frase.

<AQUÍ HAY 20 LÍNEAS VACÍAS PARA SIMULAR UN DESPLAZAMIENTO DE PÁGINA>

Sección B: Tareas Pendientes (Clave)

--------------------------------------------------

NOTA: Recordatorio de la reunión a las 14:00.

Pendiente: Revisar la configuración de seguridad del servidor web.

El error de la CLAVE-1 fue corregido en el código.

Otra tarea pendiente es documentar el proceso.

Buscaremos CLAVE-2.

<AQUÍ HAY 5 LÍNEAS VACÍAS>

Sección C: Desarrollo y Errores

--------------------------------------------------

[ERROR] Fallo en la compilación del módulo X.

Analizar el código para encontrar la CLAVE-2.

La función de búsqueda debe ser probada.

CLAVE-3.

[AVISO] Rendimiento del servidor bajo.

El texto CLAVE-1 sigue siendo importante.

CLAVE-2 aparece de nuevo.

<AQUÍ HAY 10 LÍNEAS VACÍAS>

Fin del documento.

==================================================

EOF

Sintaxis básica

cat [opciones] [archivo...]

Ejemplos prácticos

1.1. Mostrar el contenido completo de un archivo

cat notas.txt

Muestra el contenido de notas.txt directamente en la terminal.

1.2. Mostrar el contenido con numeración de líneas

cat -n notas.txt

Numera cada línea del archivo, útil para depuración o revisión.

1.3. Unir varios archivos en uno solo

nano /home/jose/parte1.txt

# Archivo 1: parte1.txt

Título: Reporte de Pruebas Diarias

Tareas completadas:

- Configuración de la red.

- Revisión de logs (sin errores críticos).

nano /home/jose/parte2.txt

# Archivo 2: parte2.txt

Resultados Pendientes:

- Falta la auditoría de seguridad.

- Pendiente: parchear el servidor principal.

Fin del reporte.

cat parte1.txt parte2.txt > completo.txt

Combina parte1.txt y parte2.txt en un nuevo archivo completo.txt.

1.4. Agregar contenido al final de un archivo existente

cat resumen.txt >> completo.txt

Añade el contenido de resumen.txt al final de completo.txt.

1.5. Crear un archivo de texto rápidamente

cat > lista.txt
Pan
Leche
Huevos
Ctrl+D

Crea lista.txt con el texto que escribas hasta pulsar Ctrl + D.

2. Comando less — Visualización paginada avanzada

less permite navegar por el contenido de archivos grandes de forma cómoda, sin cargarlos completamente en memoria.

Sintaxis

less [opciones] [archivo]

Ejemplos prácticos

2.1. Leer un archivo largo

less /var/log/syslog

Permite moverse por el archivo con las teclas:

  • Espacio → página siguiente
  • b → página anterior
  • q → salir
  • /palabra → buscar palabra hacia adelante
  • n → siguiente coincidencia

2.2. Mostrar numeración de líneas

less -N /etc/passwd

Muestra el número de línea en el margen izquierdo.

2.3. Comprimir tuberías con otros comandos

sudo dmesg | less

Visualiza la salida del comando dmesg de forma paginada.

3. Comando more — Visualización paginada simple

more fue el precursor de less. Sirve para leer archivos por páginas, aunque con menos funciones.

Sintaxis

more [archivo]

Ejemplos prácticos

3.1. Leer un archivo con avance por pantalla

more completo.txt

Avanza con la barra espaciadora y retrocede con b (limitado).

3.2. Mostrar el archivo con número de líneas

more -d completo.txt

Muestra mensajes útiles como “—Más— (Espacio: siguiente, q: salir)”.

3.3. Usar more en una tubería

cat /etc/services | more

Visualiza el contenido largo de cat con paginación.

4. Comando head — Ver las primeras líneas de un archivo

head se usa para mostrar las primeras líneas de un archivo de texto. Por defecto, muestra las 10 primeras.

Sintaxis

head [opciones] [archivo]

Ejemplos prácticos

4.1. Mostrar las 10 primeras líneas

head informe.log

4.2. Mostrar las primeras 5 líneas

head -n 5 informe.log

4.3. Usar con varios archivos

head -n 3 parte1.txt parte2.txt

Indica el nombre del archivo antes de mostrar sus primeras líneas.

4.4. Ver las primeras líneas de un comando

ps aux | head -n 10

Muestra solo las 10 primeras líneas de la lista de procesos activos.

5. Comando tail — Ver las últimas líneas de un archivo

tail permite ver las últimas líneas de un archivo o seguirlo en tiempo real (muy útil con logs).

Sintaxis

tail [opciones] [archivo]

Ejemplos prácticos

5.1. Mostrar las últimas 10 líneas

tail informe.log

5.2. Mostrar las últimas 20 líneas

tail -n 14 informe.log

5.3. Seguir un archivo en tiempo real

tail -f /var/log/syslog

Muestra nuevas líneas a medida que se agregan (útil para monitorear logs).

5.4. Seguir varios archivos a la vez

tail -f /var/log/syslog /var/log/auth.log

Muestra en vivo los eventos de ambos archivos.

5.5. Ver las últimas líneas de un comando

sudo dmesg | tail -n 15

Muestra solo las últimas 15 líneas del resultado del comando dmesg.

Resumen

ComandoPropósito principalCaracterísticas clave
catMostrar o unir archivosRápido, sin paginación
lessLeer archivos largosNavegación avanzada, búsquedas
moreLeer archivos largosPaginación básica
headVer inicio de un archivoMuestra primeras líneas
tailVer final de un archivoMuestra o sigue últimas líneas
