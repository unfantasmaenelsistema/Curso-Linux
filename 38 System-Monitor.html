System-Monitor

El script System-Monitor es una herramienta Bash diseñada para sistemas Linux/Unix que proporciona una monitorización en tiempo real del uso de la CPU, memoria y disco. El script se actualiza automáticamente cada pocos segundos y ofrece varias opciones de configuración.

Característica Descripción
Función Principal Monitoriza y muestra el uso de recursos principales del sistema (CPU, RAM, Disco) en tiempo real.
Tecnología Es un script de Shell (Bash) que utiliza comandos nativos de Linux.
Actualización El script se refresca por defecto cada 5 segundos.
Ventajas Fácil de usar, configurable (intervalo, puntos de montaje de disco) y cuenta con un instalador/desinstalador simple.

Instalación Paso a Paso

El proceso es muy sencillo ya que el repositorio incluye un script de instalación (install.sh).

Paso 1: Clonar el Repositorio

Abre tu terminal y descarga el código fuente:

git clone https://github.com/elliotsecops/System-Monitor.git

cd System-Monitor

Paso 2: Dar Permiso de Ejecución

Es necesario otorgar permiso de ejecución al script principal y al script de instalación:

chmod u+x system_monitor.sh

chmod u+x install.sh

Paso 3: Instalar el Script

Ejecuta el script de instalación. Este paso moverá el archivo ejecutable a una ubicación accesible en tu sistema (probablemente a /usr/local/bin) para que puedas llamarlo directamente desde cualquier directorio.

./install.sh

Una vez completada la instalación, ya no es necesario estar en el directorio System-Monitor para ejecutar la herramienta.

Ejecución y Uso

Uso Básico

Para ejecutar el monitor con la configuración predeterminada (actualización cada 5 segundos y monitoreo del disco raíz), simplemente escribe el nombre del script:

system_monitor

Opciones de la Línea de Comandos

Puedes usar las siguientes banderas para configurar el comportamiento del monitor:

Opción Comando de Ejemplo Descripción
Establecer Intervalo system_monitor -i 10 Configura el intervalo de actualización a 10 segundos.
Añadir Discos system_monitor -d /mnt/data Añade puntos de montaje de disco para monitorizar (puedes usar -d múltiples veces).
Cargar Configuración system_monitor -c config.sh Carga las configuraciones predeterminadas desde un archivo externo.
Ayuda system_monitor -h Muestra el mensaje de ayuda.

Detener el Monitoreo

Para detener el script de monitorización y volver al prompt de tu terminal, simplemente presiona:

Ctrl+C

Desinstalación

Si deseas eliminar el script del sistema, puedes usar el script de desinstalación incluido:

Bash

./uninstall.sh
